## 9. 已知坑（只列与本任务相关）

- **Windows shell**：`python3` 是坏桩（exit 49），一律用 `python`；`.bat` 必须纯 ASCII、GBK 编码；PowerShell 逻辑落 `.ps1`，不要内联含 `$_` 的长命令。
- **grep 计数会被 ANSI 色码干扰**：锚定匹配假报 0 命中时加 `--color=never` 或用 `git grep`。
- **长流水线**：串成一个后台脚本跑；不要用 `grep` 管道筛长命令（吞退出码、丢证据）。
- **门脚本被 gitignore 遮蔽**：清点门判据一律用 bash `grep`，不要用受 ignore 影响的搜索。
- **任务号全局跨项目**：自造 `Txxxx` 前必须探号，用只读库按 id 反查 `task_no`，不要按 +1 猜。
- **已完成任务会被物理删除**：`tasks` 表查无 ≠ 没建过；溯源看 `task_events` / `.workbuddy` result 文件。
- **04 自指**：04 不能登记自己的哈希（自指行固定 0 字节/全零，`manifest_verify` 会跳过）；改 01/02/03/05 后必须按 `manifest_resync.py` → `manifest_verify.py` 顺序重跑，否则清单里那四行哈希停留在编辑前。
- **06/07 与 04 的顺序**：先定稿 06/07，最后生成 04；否则 06 引用的 `manifest_verify` 读数会与 04 实际不符。
- **打包/ABI**：不要在并发会话运行服务时重打包（`better_sqlite3` 文件锁 EBUSY）；Electron 打包与 Node 直跑 ABI 不同，必要时用 `ELECTRON_RUN_AS_NODE`。
- **UI 实测**：真实浏览器门要连隔离实例（独立端口 + 独立 data 目录），不要碰生产 :39877；向导是原生 dialog、卡片/勾选是跨重载会话态，探针必须幂等。
- **压测读数判读**：两侧样本量差 400–800 倍时，只认「秒级 vs 毫秒级」的跨量级差；同量级摆动不可当回归；两轮不同向不宣布收益。
- **M4-b 的边界**：命中「有变更」之后仍要整行重取；`limit=500` 时签名只覆盖前 500 行，不要读成「全库变更探测」。
