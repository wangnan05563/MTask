# T03250 工作空间只读问答（PRD 5.1）

## 1. 入口与面板

- 工具栏「工作空间只读问答」按钮（`data-t03250="ask-entry"`，`MessageSquareText` 图标）紧跟在既有全文检索（`ScanSearch`）之后，同一「工作空间」语义带。
- 可见但禁用：未选具体项目、或 AI 不可用（`aiDown` → `aiBlockedTitle` 说明原因）时按钮置灰，不隐藏入口。
- 面板 `web/src/ui/WorkspaceAskPanel.tsx`：`data-t03250="panel"`，Escape / 点遮罩关闭；未绑定工作空间时明示「不可用」（`data-t03250="blocked"`）。

## 2. 只读问答链路

`POST /api/workspace/ask` → `server/src/services/workspaceQa.ts`：

1. **取证据**（只读）：`WorkspaceService.symbolMatches`（符号索引，密度高）+ `WorkspaceService.search`（前 3 个关键词各 ≤5 条全文命中）→ 按 `path:line` 去重 → 空片段用 `readFile` 回读真实行文本。
2. **预算**：`QA_EVIDENCE_LIMIT = 14` 条；单行超 `QA_ROW_LIMIT = 400` 字符截断；累计超 `QA_CONTEXT_LIMIT = 12000` 字符截断；任一截断都置 `truncated = true`（前端横幅明示，不静默）。
3. **作答**：`AIService.ask(toolId, system, user, 120_000)`，system 约束「只依据片段、每条结论标 `[相对路径:行号]`、无依据就说找不到、≤200 字、只读」。
4. **引用核验**（关键）：`parseCitations` 从回答里抽 `[path:line]` 与裸写 `path.ext:line`，**行号必须命中该文件在证据集合中的行**；同文件错行号、未知路径一律丢弃（宁少不假）。首轮零引用 → 追加硬性引用要求再问一次；仍为零 → 返回 `message` 明示「不可核验」，不把无依据回答当结论。
5. **降级**：未绑定 `kind=no-workspace`、项目不存在 `denied`、模型失败 `kind=ai`；**证据为空时不调模型**，直接如实回答「工作空间里没有找到相关依据」。

## 3. 前端

- 提问框 Enter 提交、Shift+Enter 换行；回答区 `data-t03250="answer"`，截断横幅 `data-t03250="truncated"`，引用 chips `data-t03250="cite"`。
- 点引用 chip → `GET /workspace/file?offset=line-3&limit=12`（与 `WorkspaceSearchPanel` 的 `openFile` 同一取数口径）展开 `data-t03250="file"` 并高亮引用行；再点收起。
- 页脚显示「证据 N 条 / 引用 M 处 / 关键词」，便于判断回答覆盖度。

## 4. 只读红线

本单取数只走 `WorkspaceService.search/readFile/symbolMatches`（继承既有路径防穿越与忽略规则），不写文件、不建索引、不改任务数据；驱动器对工作空间做 SHA256 全量快照、对 `tasks` 记行数，问答前后逐字节一致。

## 6. 边界

- 本单不做统计埋点（提问数/成功率/引用点击率/反馈，属 T03252），也不做「超预算/只读证明」的独立安全测试单（T03251）；本单已具备两者的可观测基础（`truncated`/`contextChars`/只读断言）。
- 证据只取符号 + 全文两条现成通道，不新增索引类型；问答不写任何持久表，因此无需清理。
