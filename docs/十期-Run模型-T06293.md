# T06293 统一 Agent Run 模型

## 任务与口径

- 任务：T06293 `[PRD] 设计 Run 模型`（urgent）
- 实际需求：`req_ids` 指向 **REQ-036《Run 数据模型》**（PRD §B6）；任务卡标签写的是 REQ-006，属于标签错位，本单以 `req_ids` 与 PRD 原文为准。
- 交付目标：定义 Run 与 RunStep 数据结构，编写数据库增量脚本，不改旧表。
- 完成口径：SQL 脚本通过；本单不包含 API、页面与历史数据回填。

## 数据模型

新增两张增量表，全部由 `server/src/db/agentRunSchema.ts` 管理：

### `agent_runs`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PK | Run 唯一标识 |
| `task_id` | TEXT NOT NULL FK | 关联任务，删除任务级联删除 Run |
| `project_id` | TEXT NOT NULL FK | 项目维度，用于项目页聚合 |
| `queue_id` | TEXT FK | 来源队列，队列删除置 NULL |
| `parent_run_id` | TEXT FK | 父 Run，支持重跑/子 Run 树 |
| `status` | TEXT CHECK | `queued/running/paused/awaiting_approval/succeeded/failed/cancelled` |
| `trigger_type` | TEXT CHECK | `manual/queue/api/schedule/retry/legacy`，对应 PRD 的 trigger |
| `model` | TEXT | 使用的模型 |
| `prompt_version` | TEXT | Prompt 版本 |
| `tokens` | INTEGER | token 用量 |
| `cost` | REAL | 成本 |
| `executor` | TEXT | 执行者（平台/会话/Agent 名） |
| `started_at` / `ended_at` | TEXT NULL | 开始/结束时间；未开始或历史补录可为空 |
| `error_code` | TEXT | 失败错误码 |
| `legacy_source` / `legacy_ref` | TEXT | 旧队列/执行会话/用量的合成 ID 来源与引用 |
| `created_at` / `updated_at` | TEXT | 审计时间 |

关键约束：
- `legacy_source` 与 `legacy_ref` 必须成对：要么都为空，要么都非空。
- 部分唯一索引 `idx_agent_runs_legacy` 保证同一旧记录只能合成一个 Run；原生 Run 不受影响。
- `queue_id` 删除置 NULL、`parent_run_id` 删除置 NULL、任务/项目删除级联。
- 复合索引覆盖项目最近 Run、任务最近 Run、状态筛选、队列归属和父子追踪。

### `agent_run_steps`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PK | 步骤标识 |
| `run_id` | TEXT NOT NULL FK | 所属 Run，删除 Run 级联删除步骤 |
| `seq` | INTEGER | Run 内序号，唯一约束 `(run_id, seq)` |
| `type` | TEXT CHECK | `prompt/tool/observation/decision/artifact/approval` |
| `status` | TEXT CHECK | `pending/running/awaiting_approval/succeeded/failed/skipped` |
| `input` / `output` | TEXT | 输入与输出，允许 JSON 文本 |
| `duration_ms` | INTEGER | 步骤耗时 |
| `cost` | REAL | 步骤成本 |
| `risk_level` | TEXT CHECK | `R0/R1/R2/R3` |
| `created_at` / `updated_at` | TEXT | 追加与状态更新时间 |

不可变追加：`trg_agent_run_steps_immutable` 锁定 `id/run_id/seq/type/input/output/risk_level/created_at`，写入后不可改；`status/duration_ms/cost/updated_at` 允许执行中推进。

## 增量与兼容

- `ensureAgentRunSchema()` 使用 `CREATE TABLE IF NOT EXISTS`、`CREATE INDEX IF NOT EXISTS` 与 `CREATE TRIGGER IF NOT EXISTS`，随 `initSchema()` 每次启动幂等执行。
- 没有 `ALTER TABLE`、没有重建旧表、没有改旧队列/执行会话/用量字段。
- 旧数据用 `legacy_source + legacy_ref` 合成 Run ID；本单只提供映射位，不做回填，旧表保持只读。
- 首版 CHECK 约束不可用 `IF NOT EXISTS` 演进；后续若改枚举，必须另做整表重建迁移。
