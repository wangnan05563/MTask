## 交付内容

### 页面壳组件

新增 `web/src/ui/layout/PageShell.tsx`：

- `PageShell`：统一内容宽度容器，最大宽度 `var(--mt-page-max, 1440px)`。
- `PageHeader`：面包屑、唯一 `h1` 标题、说明、主操作/次操作槽、视图切换槽；主操作槽标记 `data-page-primary-action="true"`，便于验收“页头主操作唯一”。
- `FilterBar`：`role="search"`，支持 `sticky` 吸顶，横向排列筛选控件；内容超出时窄屏可横向滚动。
- `index.ts`：统一出口。

新增 `web/src/ui/layout/pageShell.css`：

- 变量：`--mt-page-max: 1440px`、`--mt-page-header-space: 20px`、`--mt-page-filter-height: 48px`、`--mt-page-sticky-top: 0px`。
- 页头使用 flex 布局，标题与操作组在宽屏同行、窄屏换行。
- 筛选条 `position: sticky; top: var(--mt-page-sticky-top); z-index: 20`，背景取 `var(--app-bg)`。
- `@media (max-width: 960px)`：页头顶部对齐，筛选条 `flex-wrap: nowrap` + `overflow-x: auto`。
- 不硬编码颜色，全部复用主题变量。

### 页面接入

- `web/src/main.tsx`：引入 `./ui/layout/pageShell.css`。
- `web/src/App.tsx`：内容区左右留白由 16px 调整为 24px，统一页面基线。
- `web/src/pages/TasksPage.tsx`：根 `section` 改用 `PageShell`，新增「工作台 / 任务」面包屑、标题与说明。
- `web/src/pages/PromptsPage.tsx`：根 `section` 改用 `PageShell`，新增「AI 控制台 / 提示词」面包屑、标题与说明；原工具栏包进 `FilterBar`，保留原有控件与行为。
