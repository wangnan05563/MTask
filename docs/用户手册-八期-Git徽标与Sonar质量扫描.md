# 用户手册（八期）：Git 提交徽标、增量资产提取与 Sonar 质量扫描

> 适用版本：八期（Git 提交展示 / 增量资产提取 / Sonar 回写）及之后
> 面向：日常使用者与使用外部 AI Agent 的开发同学

---

## 1. 任务上的 Git 提交徽标

**在哪看**：任务列表每张卡片的元信息行（状态开关之后）、详情抽屉的「Git」页、看板卡标题行尾。

| 你看到的样子 | 含义 |
| --- | --- |
| `—`（灰字） | 这条任务还没有关联任何提交（待办任务正常状态） |
| `未回写`（灰标） | 任务已完成，但没有任何关联提交——建议回写，否则「这条需求对应哪次提交」将无法追溯 |
| `a1b2c3d` + 复制图标 | 已关联 1 个提交，显示 7 位简写 |
| `a1b2c3d +2` | 关联了多个提交，列表显示最新一条；点 `+2` 能看到其余 |
| `不可用`（灰字） | 环境不满足（没绑定工作空间 / 不是 Git 仓库 / 没装 git / 仓库没有 origin 远端），悬浮有具体原因 |

**能做**：

- **复制**：点复制图标得到完整 40 位 SHA，图标会变成对勾 1.5 秒；不会改变任务选中状态。
- **悬浮看摘要**：作者 · 时间 · 提交主题 · 来源（AI 回写 / 手动绑定）。键盘用户 Tab 到徽标上同样能读出同样内容。
- **点开**：平台能识别（GitHub / GitLab / Gitee / 自建 GitLab）时在浏览器打开提交页；识别不出时打开本应用的抽屉 Git 页（不会给你一个失效链接）。
- **整列隐藏**：任务工具条上的「Git」开关可整体收起徽标，切页后保持。

**「未回写」怎么办**：已完成 tab 顶部会出现提示条「本页 N 条已完成任务未回写提交 ID」，两个动作：

1. **复制回写指令**：把本页未回写任务整理成一段可直接交给外部 AI Agent 的文字（含 `mtask_link_git_commit` 调用样例）；
2. **手动关联**：打开 Git 树弹窗逐个点选。

> 提示条只统计**当前页已加载**的任务，翻页后计数随之更新。注意：已完成任务归档后可能被物理删除，补录窗口有限。

## 2. 详情抽屉的「Git」页

打开任务 → 抽屉第 6 个标签「Git」（`GitBranch` 图标）。

- **提交卡**（时间倒序）：作者与时间 → 提交主题 → `已更改 N 个文件, M 行插入(+) 删除(-)` → 分支/标签胶囊 → 7 位简写 + 复制 + 平台外链。标「主提交」的是最新一次关联；标「AI 回写 / 手动绑定」的是来源。
- **文件清单**：点开提交卡后按需加载，状态徽标 `A` 新增（绿）/ `M` 修改（橙）/ `D` 删除（红）/ `R` 重命名（蓝，显示 `旧 → 新`），二进制文件标「二进制」。点文件行展开 diff。
- **刷新**：Git 页每次打开都会实时查询；区头「刷新」按钮手动重取，刷新期间保留旧内容（不闪烁清空）。
- **关联 / 解绑**：空态或底部有「关联提交」——在 Git 树弹窗里按分支/标签过滤、搜索、多选，确认后即时生效。只有**手动绑定**的提交能解绑（AI 回写的不受影响），解绑有二次确认。
- **子任务区**：抽屉底部「子任务 N」列出挂在它下面的子任务（含 Sonar 回写出来的问题单），点击可直接跳转。
- **失败提示**：不是仓库 / 没装 git / 没有 origin / 超时 / 仓库过大，各有对应说明和下一步（例如「去绑定工作空间」）。

## 3. AI 工作台：Git 增量资产提取

位置：AI 工作台能力卡片区，「代码评审会议讲稿」之后。**不消耗 AI 额度**。

1. **选范围**：勾项目（必须同一工作空间，否则该行禁用并提示）→ 勾任务（只列已回写提交的任务，未回写的置灰并说明「未回写 commit id」）。顶部常显「已选 3 个项目 / 12 个任务 / 共 47 个文件」。
2. **选方式**：
   - **源文件提取**：按仓库相对目录结构打包 zip；
   - **Excel 清单**：9 列（提交 / 文件路径 / 变更状态 / 新增行 / 删除行 / 任务编号 / 任务标题 / 作者 / 提交时间）；
   - **Markdown 清单**：同字段表格 + 提交摘要。
3. **执行**：分阶段进度（汇总 → 读取 → 打包 → 可下载）+ 逐任务成功/失败回执，可随时「中止」（中止即回收临时文件）。

**限制（超限直接报错并给出当前计数，不会悄悄放过）**：

- 文件数 ≤ 2000、总体积 ≤ 50MB、任务数不限；
- 同一秒提交 + 无父子关系 + 改了同一文件 → 会点名报错，请拆开分两次导出（这是刻意的：不替用户猜先后）；
- 同时最多 2 个导出任务，超出的请求会被拒绝并提示「已有 2 个导出在跑，请稍后重试」（不排队）。

**只读**：导出只读仓库内容，不会 checkout、不会改动你的工作区；中间文件写在应用数据目录的临时区，6 小时后自动清理。

## 4. AI 工作台：Sonar 质量扫描

位置：「Git 增量资产提取」之后，同样**不消耗 AI 额度**。

### 4.1 先配置（设置 → SonarQube）

| 配置项 | 说明 |
| --- | --- |
| 服务器地址 | 填 `http(s)://…`，保存时会自动去掉尾部斜杠并做连通性测试 |
| 认证 Token | 加密存储；默认只显示脱敏串；点「查看原文」需要二次确认，**且会留下审计记录** |
| 扫描器路径 | 留空则自动在 PATH 里找 `sonar-scanner` |
| Java 环境 | 只读显示探测结果，不提供安装 |
| projectKey 映射 | 工作空间/项目 ↔ Sonar projectKey；没配的项目在扫描面板会提示去配置 |
| 扫描并发 | 默认 1，可调到 2 |

**连接测试**分别给出：服务器连通性（含版本与版型）、扫描器可用性、项目键可达性；失败会区分 `unreachable / auth-failed / no-scanner / no-java / project-not-found` 并给对应指引。

### 4.2 发起扫描

选范围（与导出卡共享同一套选择器、沿用上次范围）→ 确认每个项目都有 projectKey → 开始。阶段：汇总 → 快照 → 配置 → 扫描 → 等待 Sonar 分析队列 → 拉取问题 → 回写。日志实时流到 AI 控制台，刷新页面后卡片上的运行徽标仍能恢复。

- **扫的是提交快照，不是你现在的工作树**：结果页会注明「快照基于 SHA x，当前 HEAD 为 y，相差 n 个提交」。
- 完成后按严重度分组（阻断 / 严重 / 主要 / 次要 / 提示），可点「在 SonarQube 打开报告」跳服务器看完整报告。
- 中途可「中止」，临时快照立即回收。

### 4.3 问题自动回写为子任务

- 默认只回写 `blocker/critical`，阈值可在设置页调整；每次最多回写 50 条，多出的合并成 1 条「[Sonar] 本次扫描另有 N 个问题」汇总子任务（描述含完整清单与报告外链）。
- 回写到**原任务的子任务**；如果原任务本身就是子任务，会挂到它的父任务下（不产生三级嵌套），描述里注明实际归属。
- 标题形如 `[Sonar] {规则键} {路径}:{行}`，优先级按严重度映射（阻断/严重 → 高，主要 → 中，次要/提示 → 低）。
- 同一条问题 7 天内不会重复建单（按 `规则|路径|行|消息` 指纹去重）。
- 外部 Agent 的修复闭环：在 MTask 里领这些子任务即可，修复后照常用 `mtask_link_git_commit` 回写提交。

### 4.4 没装 Sonar 怎么办

卡片会显示为不可用并给出安装指引，不会弹错误框，也不会留下跑了一半的任务；其他功能不受影响。

## 5. 隐私与安全提示

1. **仓库只读**：所有 Git 操作都是只读子命令（查看提交、读取文件内容、读远端地址），不会写你的仓库；导出与扫描的中间文件只落在应用数据目录的临时区。
2. **凭据剥离**：远端地址若含用户名/令牌（`user:token@…`），展示与打开前会剥离。
3. **Token**：加密存储，不进日志、不进命令行、不进临时 properties；临时 properties 随快照目录一起清理。查看原文会记录审计。
4. **外链只允许 http/https**：界面层与主进程各校验一次。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 徽标显示「不可用」 | 悬浮看原因：先确认项目已绑定工作空间；确认目录是 Git 仓库；确认装了 git；确认仓库有 origin 远端 |
| 徽标一直「未回写」 | 让外部 Agent 提交后调用 `mtask_link_git_commit`；或在抽屉里手动关联 |
| 关联的提交在抽屉里查不到内容 | 项目工作空间可能已换绑，旧 SHA 在新仓库不存在——回执会明确说明，重新关联即可 |
| 导出报「超出上限」 | 减少勾选的任务，或按提示拆成多次 |
| 扫描卡灰 | 设置页看连接测试三项哪项红：没装 scanner / 没装 Java / 地址或 Token 错 / projectKey 没配 |
| 扫描完成后没看到子任务 | 检查阈值设置（默认只回写阻断/严重），以及是否 7 天内已建过同指纹的单 |
