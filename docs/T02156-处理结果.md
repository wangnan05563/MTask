## 优化方案（详见 docs/T02156-启动会PPT品牌优化策略.md）

1. **品牌四色进单源**：`exportStyle.ts` 新增 `BRAND_DEEP=08409C / BRAND_BRIGHT=0059E9 / BRAND_PALE=C9DCF6 / ON_BRAND=FFFFFF`（恒生模板版式取色），`kickoff-layout.ts` 的 `PALETTE` 只引用，`auditPalette` 加三对对比度断言（全 ≥4.5）。
2. **背景资产版式化（绕过 N1）**：恒生三张版式背景提取为 1280×720 JPEG 进 `server/src/services/assets/kickoff/`（封面/目录/内容），`defineSlideMaster({ background })` 登记为自定义版式，页面按 layout 选版式——**不引 Python、不加依赖、不走母版套用**；同图 14 页共用只落一份媒体（逐页贴会被复制 14 份，150KB→1.1MB）。
3. **装配层显式声明**：标题/页脚墨黑→品牌深蓝；表头浅靛蓝墨字→品牌深蓝白字；时间线条→品牌亮蓝、菱形/轴→品牌深蓝（去掉与「已达成」语义相反的警示红）；图表四类文本（catAxis/valAxis/dataLabel/legend）字体全部微软雅黑、颜色全部墨色，绘图区白底成图表卡片。
4. **数字呈现**：`fmtNum`（1 位小数）只作用于派生量（P84/阶段分布），合计行保持库内原值（验收 6 比对值不动）；页脚同步。
5. **门禁同步**：t02100/t02101/t02111 的「全稿零位图」收紧为「内容零位图」（slide 无 `<p:pic>`、无任何 `r:embed`，背景 embed 全在版式层）；新增 `verify-t02156-kickoff-brand.mts` 26 断言。
