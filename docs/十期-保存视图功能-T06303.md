# 十期 · 保存视图功能（T06303 / PRD §B1）

## 1. 范围

在任务页提供可命名的保存视图：把当前视图类型（列表/看板）、关键词、分类、优先级、字段筛选、排序、密度与看板空列开关保存为项目级或私有配置，支持应用、复制、删除；同时把当前视图状态写入 URL，刷新后恢复。不包含 PRD §B1 中表格列宽拖拽、字段显示配置、分组、日历视图与 5k 任务性能基准。

## 2. 入口与交互

- 任务页工具条在视图切换按钮右侧挂载 `SavedViewMenu`（`data-t06303="saved-view-menu"`）。
- 下拉列出当前项目的保存视图，选项后缀标明「共享 / 私有」；未选中时复制、删除按钮禁用。
- 「保存」读取当前页面状态生成 config，弹出命名输入；确认后询问是否设为项目共享，取消则保存为私有。
- 选择视图后立即应用 config：切回对应视图、恢复筛选/排序/密度，并同步 URL。
- 「复制」调用专用接口，重名自动追加「（副本）」「（副本 2）」；「删除」只删除配置行，不动任务数据。
- URL query 使用 `view/q/cat/priority/field/op/fvalue/fsort/density/boardHide`；页面首次加载按 URL 恢复，状态变化回写 URL，刷新不丢。

## 5. 边界与未覆盖

- 任务描述引用的 AC-03 是「看板快速滚动 60fps」，与 §B1 保存视图功能不是同一验收口径；本单未做 5k 任务性能测试，不能声称满足 AC-03。
- PRD §B1 的表格列宽拖拽、字段显示配置、分组、日历视图、行内编辑不在本单 config 白名单与页面状态内；需要后续单独立项。
- 「分享」当前仅表达为 `visibility=project`（项目内共享）与 `private`（本机私有），没有用户/权限体系；单机假设下可用，多用户权限需另做。
- URL 仅覆盖当前已支持的筛选/排序/密度等状态，不包含列宽和分组。
- 生产库未执行迁移；测试使用隔离数据目录与测试服务，验收后应清理测试数据。
