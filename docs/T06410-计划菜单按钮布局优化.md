# T06410 计划菜单按钮布局优化：更多展开及悬浮显示

## 目标与结论

计划页工具栏完成与任务页一致的行尾「更多」展开式布局：移除 `TaskMoreMenu` 下拉菜单，新增行尾触发按钮与行内展开面板；AI 评估、补算复杂度、多选迁移到刷新按钮前，默认隐身、悬浮显示。浏览器探针 20/20 PASS，静态门禁 PASS，Web 构建通过。

## 实现

### 1. 「更多」由下拉改为行内展开

`PlanMoreMenu` 不再调用 `TaskMoreMenu`，改为：

- 触发按钮固定在工具条行尾：`marginLeft: 'auto'`，窄屏换行后仍贴当前行右侧。
- `aria-expanded` 绑定展开状态；点击切换，`Esc` 收起并把焦点还给触发按钮，外点收起。
- 展开面板 `order: 9 + flexBasis: 100%`，独占工具条下一行；分类组与按钮行均允许换行，面板与页面均不产生横向滚动。
- 面板按「计划 / 数据 / 分享」三组承载原六个入口：新建计划任务、导入 Excel、导出 Excel、导出 Markdown、下载模板、分享快照。
- 原回调、禁用条件、隐藏 file input、`ShareSnapshotDialog` 状态全部保留。

### 2. 三按钮迁移与显隐

工具条顺序调整为：

`视图切换 → PRD 管理 → PRD/矩阵/用例/迭代/洞察/Webhook → 节假日管理 → AI 评估 → 补算复杂度 → 多选 → 刷新 → 更多`

- AI 评估保持 `op-hidden`；补算复杂度新增 `op-hidden`；多选仅在未激活时隐身，激活后常显（便于退出多选）。
- 三者均由 `.op-host:hover` / `:focus-within` 控制，键盘仍可 Tab 到达，触屏/粗指针设备常显。
- AI 不可用提示条、评估进度输出、批处理栏与原有业务逻辑不变。
