# 十期任务菜单 AI 梳理摘要按钮布局交互优化（T06334）

- 任务编号：T06334
- 项目：MTask十期
- 日期：2026-11-25
- 验收范围：任务菜单内「AI 梳理摘要」入口的位置、组件替换、点击动效、悬浮提示、响应式与无回归。

## 根因

T06334 的初始实现（提交 `809cd9c1`）已经把入口放在描述「展开」按钮之前，并复用 `IconButton` 的 ghost/sm 样式，但仍暴露三个问题：

1. **没有真正使用 Design System Tooltip**：图标按钮只依赖原生 `title` 属性，悬浮提示是浏览器原生 title，不是项目 UI 库的 Tooltip，无法满足“显示功能名称 + 功能简述”的双行样式要求。
2. **Tooltip 气泡宽度坍缩**：`mt-tooltip__bubble` 只有 `max-width`，没有 `width: max-content`，在任务行这种窄容器里会被压成极窄竖条，文案逐字换行。
3. **Tooltip 被任务行裁切**：任务行 `.task-item` 使用 `content-visibility: auto`，会建立 paint containment；绝对定位的 Tooltip 气泡会被行框裁掉，悬浮时看不完整。

## 影响范围

- 任务列表（列表视图）中所有带 `aiSummary` 的任务行。
- 摘要入口的按钮语义、悬浮提示、展开/收起状态与响应式布局。
- 纯前端交互，不修改任务摘要或任务数据。

## 修复（绝对路径与改动点）

### 1. 摘要按钮改用 Design System Tooltip

`D:\code\otherProjects\MTask\web\src\pages\TasksPage.tsx`

- 摘要入口由直接渲染 `IconButton` 改为包在 `Tooltip` 内，`placement="bottom"`。

  - `AI梳理摘要`（功能名称，加粗）

- 点击仍只切换 `summaryExpanded`，不联动描述展开；`aria-expanded` 与提示文案随展开态同步（展开后为“收起任务摘要”）。
- 给按钮传 `title=""`，禁用原生 title，避免原生 title 与 Tooltip 双提示。

### 2. 允许调用方覆盖 IconButton 的原生 title

`D:\code\otherProjects\MTask\web\src\ui\components\IconButton.tsx`

- 解构增加 `title`，并改为 `title={title ?? label}`。
- 既有调用方不传 `title` 时仍默认 `label`，行为不变；摘要入口显式传空串以关闭原生 title。

### 3. 修复 Tooltip 气泡宽度
