# T03256 建议台账与采纳率（AI-203 ②③）

## 1. 范围与拆分

| 验收条 | 本单 | 承接单 |
|---|---|---|
| ② `suggestion_id` 记录 shown/accepted/dismissed/timeout 与采纳率 | ✅ | 本单 |
| ③ 功能可关闭 | ✅ | 本单 |
| ① 建议内容与理由 | 依赖 | T03255（已交付） |
| ④ 未启用可隐藏 / 配置失效按 D-14 显示禁用原因 | — | T03257 |

T03255 只管「给出建议」，本单补上「建议被看到之后发生了什么」：展示即入账、终态只记一次、采纳率可回看、可整体关闭。

## 2. 数据层

`server/src/db/schema.ts` 新增表 `ai_suggestions`：

| 列 | 说明 |
|---|---|
| `suggestion_id` | 主键（uuid），生成建议时即分配给前端 |
| `card_key` | 固定 `ai.category_suggest`，与 `ai_usage.card_key` 同一命名习惯 |
| `project_id` / `task_id` | 来源项目与任务（新建场景 `task_id` 为空） |
| `category_id` / `priority` / `reason` | 建议值快照——统计时不依赖当前任务、也不受建议后任务被改影响 |
| `status` | `shown` → `accepted` / `dismissed` / `timeout`，单向 |
| `created_at` / `updated_at` | 展示与终态时间 |

索引 `idx_ai_suggestions_card_status(card_key, status, created_at)` 服务于按卡片/状态的统计查询。

## 3. 服务层

`server/src/services/aiSuggestion.ts`：

- `suggestionsEnabled()` / `setSuggestionsEnabled(bool)`：开关存 `app_settings`（`ai.suggestions.enabled`，默认开）。
- `recordShown(input)`：插入一行 `shown` 并返回 `suggestion_id`。
- `markStatus(id, event)`：只允许 `shown → 终态` 一次；重复上报（网络重试/双击）返回当前终态；未知 id / 非法事件名返回错误，不靠唯一约束报错兜底。
- `suggestionStats({cardKey?, projectId?})`：**分母 = shown + accepted + dismissed + timeout**（即「已展示数」）。未处理的 `shown` 也留在分母里——否则停留未处理的建议会被悄悄移出分母，采纳率虚高。无展示时 `adoptionRate = null`，界面上显示「暂无数据」而不是 0%。

## 4. 路由

`server/src/routes/taskSuggest.ts` 扩展（挂载不变）：

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/api/tasks/classify-suggest` | 开关关闭时直接返回 `{ok:false, disabled:true, error}`，**不调模型、不记 shown**；成功时附 `suggestionId` |
| POST | `/api/tasks/classify-suggest/feedback` | `{suggestionId, event}` → 终态；幂等 |
| GET | `/api/ai/suggestions/stats` | 返回 `enabled` + `shown/accepted/dismissed/timeout/adoptionRate`，可按 `projectId` 过滤 |
| PUT | `/api/ai/suggestions/enabled` | `{enabled: boolean}`，非布尔 400 |

关闭期间不记 `shown`：否则关闭时段的展示会污染采纳率分母；历史台账保留不清零。

## 5. 前端

### 5.1 任务页（`web/src/pages/TasksPage.tsx`）

- 建议对象增加 `suggestionId`；所有终态都回传台账，失败静默（统计旁路不挡主流程）：
  - 点「采纳」→ `accepted`（仍是 T03255 语义：新建只填表单、行内才写任务）；
  - 点「不用」→ `dismissed`；
  - 建议条停留 120s 未处理 → 自动收起并记 `timeout`；
  - 标题/描述被修改、换任务重新取建议、新建建议被下一次请求覆盖 → 旧建议按 `dismissed` 结算，不留悬挂 `shown`。
- 页面挂载时读取 `/api/ai/suggestions/stats` 的 `enabled`；关闭时新建与行内的建议入口整体不渲染（与服务端拒绝生成双端一致）。

### 5.2 设置页（`web/src/pages/SettingsPage.tsx`）

「设置 → 通用」新增「任务分类建议」区块（`data-t03256="suggest-settings"`）：

- 开关按钮直接落 `app_settings`，关闭/开启即时生效；
- 旁边显示采纳率（`data-t03256="suggest-stats"`）：`采纳率 50.0%（1/2 条已展示）`；无展示时显示「暂无数据」。

## 7. 边界与后续

- 采纳率是「建议层面」的指标，不追踪采纳后用户是否又手改；后者如果要做，属于任务变更审计范围。
- 「从未启用可隐藏、启用后配置失效按 D-14 显示禁用原因」由 T03257 承担；本单只做「用户主动关闭」的显隐。
- 台账目前只在设置页展示汇总；按卡片的明细列表未在本单范围内。
