# 项目管理 · 使用向导（T00665）演示说明

> 本文档为向导引导功能的**演示素材说明**（配套交互式演示动画），可随功能一起复用。

## 一、功能组成

| 组成 | 说明 | 代码位置 |
|---|---|---|
| 首次访问引导弹窗 | 检测到用户首次进入项目管理模块时**自动弹出**；5 步向导覆盖各子功能 | `web/src/pages/ProjectGuide.tsx` |
| 常驻向导按钮 | 页面工具条**右上角**「向导」按钮（呼吸动画）；随时重新唤起弹窗 | `PlanPage.tsx`（工具条末位） |
| 步骤指示器 | 顶部进度条（5 段），可点击跳转到任意步骤 | `ProjectGuideDialog` 内部 |
| 交互式演示动画 | 每步内嵌轻量 CSS 动画，模拟真实交互（排序菜单/图钉置顶/甘特排期/矩阵关联/导入流程） | `StepDemo` 组件 |
| 状态持久化 | `localStorage['mtask.projectGuide.seen']` | `hasSeenProjectGuide` / `markProjectGuideSeen` |

## 二、演示脚本（全流程）

### 1. 弹出触发条件
1. **首次访问**：清除浏览器缓存（或 `localStorage.removeItem('mtask.projectGuide.seen')`）后进入「项目管理」菜单 → **向导弹窗自动弹出**（约在页面加载后立即出现）。
2. **非首次访问**：弹窗**不再自动出现**（标记为已看）。
3. **再次查看**：点击工具条右上角「**向导**」按钮 → 弹窗重新打开（无论是否已看过）。

### 2. 按钮交互行为（演示要点）
| 操作 | 结果 |
|---|---|
| 「下一步」/「上一步」 | 在 5 个步骤间切换；顶部进度条同步高亮 |
| 点击进度条任一段 | 直接跳到该步骤 |
| 「跳过」/「开始体验」/右上角 × / 点击遮罩 / Esc | 均关闭弹窗，并**记录已看状态**（下次不再自动弹出） |
| 常驻「向导」按钮 | 带呼吸动画（`task-breathe`）；点击随时重新打开（状态持久化，刷新页面按钮不消失） |

### 3. 状态持久化逻辑（演示要点）
```
进入项目管理页
   └─ hasSeenProjectGuide()?  ── 否 ─→ 自动打开向导
                             └─ 是 ─→ 仅显示右上角常驻按钮
用户关闭/跳过/完成向导
   └─ markProjectGuideSeen() → localStorage 写入 'mtask.projectGuide.seen' = '1'
清除浏览器缓存 / 隐私模式
   └─ 标记丢失 → 恢复「首次访问」行为（符合需求约束）
```

## 三、向导内容一览（5 步）

1. **认识「项目管理」**——模块定位与入口全景（下拉统计徽标 / 列表与甘特 / 相邻入口）
2. **项目排序与置顶**——排序按钮（7 种方式，跨会话保持）、图钉置顶、**拖拽排序**
3. **列表与甘特视图**——行内编辑、时间轴/周末底纹/今日线、工期变更自动重排
4. **需求跟踪矩阵**——需求 ↔ 计划/待办关联、关联调整、增删改
5. **导入导出与节假日**——Excel 模板导入导出、AI 工作台导入入口、节假日重排

每步均含一段**可复用演示动画**（纯 CSS，无视频资源依赖，体积为零）。

## 四、约束满足说明

| 约束 | 实现 |
|---|---|
| 不修改核心业务逻辑 | 向导为纯附加层：仅在页面加入弹窗组件与一个按钮，未触碰计划/矩阵/甘特逻辑 |
| 兼容主流浏览器与移动端 | 弹窗宽度 `min(560px, 92vw)`、内容可滚动、底部按钮可换行；无平台专有 API（仅 localStorage，隐私模式下静默降级） |
| 清缓存恢复初始引导 | 状态仅存 localStorage，清除即恢复首次引导 |
| 动画性能 | 演示动画仅使用 `transform`/`opacity`（GPU 合成层），无布局抖动；常驻按钮呼吸动画为既有通用动画 |
| 可访问性 | 弹窗 `role="dialog"` + `aria-modal`、按钮均有 `aria-label`/`title`、Esc 关闭、步骤指示器可键盘操作 |

## 五、手工验收清单

- [ ] 清缓存后首次进入「项目管理」→ 向导自动弹出
- [ ] 逐步「下一步」走完全部 5 步，各步演示动画正常播放
- [ ] 点「跳过」→ 弹窗关闭；刷新页面 → **不再自动弹出**
- [ ] 点右上角「向导」→ 弹窗重新打开
- [ ] 记录已看后刷新页面 → 向导按钮**仍存在**（状态持久化）
- [ ] 移动端窗口（窄屏）→ 弹窗自适应、内容可滚动、按钮不溢出
- [ ] Esc / 点击遮罩 / × → 均可关闭且记录已看
