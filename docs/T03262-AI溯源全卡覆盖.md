## 1. 背景与范围

报表卡（`ai.weekly_report`）在 T03240/T03241 已有：溯源面板、导出稿溯源段、产物持久副本与找回。
其余长文本卡——PRD 生成、测试用例生成、代码评审讲稿、阶段总结 PPT、启动会 PPT——此前只有「生成成功」，
没有溯源，也没有可找回的产物路径。

本次覆盖 5 张卡（周报不重复做）：

| 卡片 | cardKey | 生成入口 | 溯源落库位置 |
| --- | --- | --- | --- |
| PRD 生成 | `ai.prd_gen` | `routes/index.ts`（`/plans/prd-generate-stream`） | `PrdGenService.generate` 内 |
| 测试用例生成 | `ai.test_case_gen` | `routes/index.ts`（`/plans/testcase-generate-stream`） | `TestCaseGenService.generate` 内 |
| 代码评审讲稿 | `ai.code_review_lecture` | `routes/plans.ts`（SSE） | 讲稿流 done/aborted 前 |

单调用/短文本卡（优化、分类、评估等）不在范围：它们没有「长稿 + 截断 + 产物文件」三件套，溯源行会退化成一堆噪声。

## 2. 设计：为什么落库而不是塞进 SSE done

两张卡的生成路由在 `routes/index.ts`，该文件当时被并行改动占用（行级冲突面大）。
把溯源塞进每张卡的 SSE `done` 需要逐个改这些路由；改成**生成端落一份快照 + 面板按 cardKey 取回**后：

- 生成侧只多一次 `recordCardProvenance()`，不改变任何 SSE 事件形态（前端控制台解析零改动）；
- 面板重进/刷新时不需要「这次没生成过」的前置条件——库里有的就是最近一次真实生成；
- 导出稿、面板、`ai_artifacts.provenance` 消费同一份 `rows`，逐字同源（AI-101 ③）。

新增表（`server/src/db/schema.ts`）：

```sql
CREATE TABLE IF NOT EXISTS ai_card_provenance (
  id TEXT PRIMARY KEY, card_key TEXT NOT NULL, project_id TEXT,
  payload_json TEXT NOT NULL, created_at TEXT NOT NULL);
CREATE INDEX IF NOT EXISTS idx_ai_card_provenance_card ON ai_card_provenance(card_key, created_at);
```

查询路由：`GET /plans/ai-card-provenance?cardKey=&projectId=` → `{ ok, provenance | null }`。
`projectId` 为空时取该卡全局最近一份；给了就严格按项目过滤（`project_id IS ? OR ? IS NULL`），避免看到别的项目的溯源。

每卡保留 `CARD_PROVENANCE_KEEP = 30` 份：只服务「重进页面看最近一次」，留多了是历史噪声。

## 3. 行口径（`buildCardProvenance`）

固定顺序：**来源 → 时间窗（可选）→ 截断 → 模型 → 生成时间**。

- 截断无时写「无」而不是省略行——省略会让「没有这一行」和「有截断但为 0」分不清；
- 模型未知写「未记录」，绝不猜一个模型名（讲稿结果对象不携带模型）；
- 来源值允许为空则整行剔除；字符数统一千分位（`12,480 字`）；
- `truncated` 是面板取警示色的唯一依据，导出稿据此在标题加 ⚠。

前端 `CardProvenancePanel` 与报表卡同款：桌面默认展开、窄屏（≤820px）默认折叠、用户选择按卡记在
`localStorage card.prov.<cardKey>`。

> 踩坑：`<details>` 的 `open` 被宽度变化改写时也会触发 `toggle` 事件。早期实现把每次 toggle 都当用户选择写回去，
> 结果是「桌面看过一次 → 窄屏永远打不开」。现在只在 `open !== 上次渲染值` 时才记——宽度驱动变化不算选择。

## 4. 产物找回（AI-101 ④⑥）

`recordArtifact({ cardKey, filename, buffer, provenance })` 在每次生成/导出成功后落一份持久副本
（`DATA_DIR/artifacts/<cardKey>/`，每卡 20 份），面板通过 `GET /report/artifacts?cardKey=&limit=1` 取最近一份：

- 路径常驻（可复制）；
- 「打开目录」走 `desktopApi()?.revealPath`，浏览器形态置灰并写「仅桌面端可用」；
- 文件被清理时显示「文件已不在」，不给死链；
- 溯源块**不挂**「本次有结果」条件：刷新后草稿/结果清空，也要能找回上一次。

## 5. 导出稿同源

- `exportProvenance(raw, cardKey, fallback, projectId)`：前端回传行优先 → 其次取该卡最近一次落库快照 → 最后才按导出时取数兜底；
- 讲稿导出：md 追加文末「## 溯源」段，docx/pptx 追加末节（`sections` 上限 24，满了不塞，避免超限被截稿）；
- 用例导出：md 追加末段、docx 追加 HEADING_1 节、xlsx 多一个「溯源」页签；
- PRD 文档导出：三种格式都追加溯源段；
- 导出产物同样登记 `recordArtifact`，导出件丢了也能按卡找回。
