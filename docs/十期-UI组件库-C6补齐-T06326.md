## 2. API 摘要

### 表单类

| Prop | 适用 | 说明 |
|---|---|---|
| `label` / `hint` / `error` | Select / Checkbox / Radio / Switch | 自动 `htmlFor`；`hint`/`error` 写入 `aria-describedby`；error 同时写 `aria-invalid` / `aria-errormessage`，文案 `role=alert` |
| `size` | 四者 | `sm` / `md`（Select 另有 `lg`） |
| `loading` | 四者 | 禁用交互 + spinner + `aria-busy` |
| `indeterminate` | Checkbox | 原生 `input.indeterminate`，含横线视觉 |
| `checked` / `defaultChecked` / `onCheckedChange` | Switch | 受控/非受控；`role=switch` + `aria-checked`；`name` 存在时输出 hidden 值 |
| `options` / `placeholder` | Select | 原生 option 列表；placeholder 为禁用空值项，required 时不选空值 |

### 浮层类

| 原语 | 必填 | 关键 Props |
|---|---|---|
| Dialog | `open`、`onClose`、`title` | `description`、`children`、`footer`、`size=sm/md/lg`、`closeOnOverlay`、`closeOnEsc`、`showClose` |
| Drawer | `open`、`onClose`、`title` | `description`、`children`、`footer`、`side=left/right`、`width`、`closeOnOverlay`、`closeOnEsc` |
| Popover | `trigger`、`triggerLabel`、`children` | `placement=bottom-start/bottom-end/top-start/top-end`、`open`、`defaultOpen`、`onOpenChange`、`label` |
| Tooltip | `content`、`children` | `placement=top/bottom/left/right`、`delay`、`open`、`maxWidth` |

浮层规则：

- Dialog/Drawer 使用 portal；SSR 时返回空，不触碰 `document`。
- 打开时记录 `document.activeElement`，关闭/卸载时回落；Tab 在面板内循环。
- Dialog/Drawer 遮罩点击只在 `event.target === overlay` 时关闭，面板内点击不误关。
- Popover 点击外部或 Esc 关闭；ArrowDown 从触发器打开；打开后聚焦面板首个可聚焦元素。
- Tooltip 只做说明，不接收点击（`pointer-events:none`），Esc 立即隐藏。

### 结构与反馈类

| 原语 | API |
|---|---|
| Tabs | `items: {key,label,content,disabled?,badge?}[]`、`value/defaultValue`、`onValueChange`、`variant=line/pill`、`size`、`fitted` |
| Toast | `ToastProvider(duration,max)` + `useToast()` 返回 `{toast,dismiss,clear}`；`Toast` 可单独展示，支持 tone/title/description/action/onClose |
| ErrorState | `title`、`message`、`details`、`icon`、`retry:{label,onClick,loading}`、`compact` |
| Toolbar | `start`、`center`、`end`、`children`、`ariaLabel`、`variant=default/plain/card`、`density`、`wrap`、`sticky` |
| Panel | `title`、`subtitle`、`extra`、`footer`、`children`、`variant=default/muted/outline`、`padding=none/sm/md/lg`、`collapsible/defaultCollapsed` |

## 4. Token 与硬编码约束

- 颜色只消费 `--mt-semantic-*` / `--mt-component-*`。
- 新增 TSX 与 `components.css` **零 `#hex`、零 `rgba()`、零 `--mt-primitive-*` 直引**。
- 阴影统一用 `var(--mt-semantic-overlay)`；Toast 背景用 `--mt-component-toast-bg`，Drawer 用 `--mt-component-drawer-*`。
- 尺寸（px）允许常量；颜色不得绕过语义层。
