# 通用提示词：任务列表视图按钮风格（MTask 设计语言）

> 来源：`web/src/pages/TasksPage.tsx` 列表视图按钮体系（2026-09-13 提取）。
> 用法：把下文「提示词正文」整段粘贴给 AI，即可在其他页面/项目生成视觉与交互一致的按钮。

---

## 提示词正文

为页面生成与以下规范完全一致的按钮体系（React + 内联样式 + 页面级 `<style>` 块，lucide-react 图标库）：

### 1. 设计令牌（一律用主题 CSS 变量，禁止硬编码 rgba/hex 常量色）

- 背景层级：`var(--card-bg)`（按钮底）、`var(--surface-2)`（hover 行底）、`var(--bg)`（输入框底）
- 强调与文字：`var(--accent)`（选中/主操作底）、`var(--accent-text)`（强调底上的文字）、`var(--text)`（默认文字）、`var(--text-muted)`（次要文字）、`var(--danger)`（破坏性操作）、`var(--success)`（成功/完成态）
- 边框：`var(--border)`（弱边框/记录行）、`var(--border-strong)`（控件描边/分隔线）
- 字号基准 12px；图标 13px（工具栏大图标 18px）；圆角：控件 6px、记录卡片 8px、内嵌元素 4px

### 2. 工具栏按钮（文字型）

```
display: inline-flex; align-items: center; gap: 4;
padding: 5px 8px; border-radius: 6;
border: 1px solid var(--border-strong); background: transparent;
color: var(--text); font-size: 12; cursor: pointer;
选中态：background: var(--accent); color: var(--accent-text);
```

- 有 busy 态时 `disabled` + 文案切换（如「分类中…」），配 Loader2 旋转（`@keyframes aispin { to { transform: rotate(360deg) } } .aispin { animation: aispin .8s linear infinite }`）

### 3. 图标按钮动画（统一类 `.tbtn-anim`）

```css
.tbtn-anim svg { transition: transform .18s ease; }
.tbtn-anim:hover svg { transform: scale(1.2) rotate(8deg); }
.tbtn-anim:active svg { transform: scale(.88); }
```

- 纯图标、无文字标签；必须带 `title`（功能说明）+ `aria-label`（无障碍）
- busy 态：图标换 `<Loader2 className="aispin" />` 旋转；长任务叠加 `.task-breathe` 呼吸（见 §6）

### 4. 分段切换控件（列表/看板类视图切换）

- 外层容器：`display: inline-flex; border: 1px solid var(--border-strong); border-radius: 6; overflow: hidden`
- 段内按钮：`padding: 5px 9px; border: none; border-left: 1px solid var(--border-strong)`（首段无左边框），选中段 `var(--accent)` 底，图标化 + `.tbtn-anim`

### 5. 行操作按钮（`.task-op`，悬浮显示）

```css
.task-op { opacity: 0; visibility: hidden; transition: opacity .15s ease, visibility 0s linear .15s; }
.record-row:hover .task-op, .record-row:focus-within .task-op { opacity: 1; visibility: visible; transition: opacity .15s ease, visibility 0s; }
```

- 常规尺寸 `font-size: 12; display: inline-flex; padding: 2px 4px`；破坏性操作 `color: var(--danger)`
- `focus-within` 必须保留（键盘 Tab 可达）；编辑态（`.task-editing`）常显

### 6. 记录行与状态动画

- 记录行：`border: 1px solid var(--border); border-radius: 8; transition: background-color .15s ease, transform .12s ease`，hover 底 `var(--surface-2)`，`:active { transform: scale(.985) }`（点击微缩放）
- 刷新/数据变更闪烁：`@keyframes rowflush { 0% { background: var(--accent-soft) } 100% { background: transparent } }`，`.flush { animation: rowflush 1.4s ease }`
- AI busy 呼吸：`@keyframes task-breathe { 0%,100% { transform: scale(1); box-shadow: 0 0 0 0 rgba(37,99,235,.35) } 50% { transform: scale(1.06); box-shadow: 0 0 0 5px rgba(37,99,235,0) } }`，`.task-breathe { animation: task-breathe 1.3s ease-in-out infinite }`（同时用于按钮与「正在…」文案）

### 7. 硬性约束

- 所有交互元素带 `title` + `aria-label`（悬浮提示文案 =「功能名 — 一句话说明」）
- 破坏性操作用 `var(--danger)` 且悬浮提示写明后果与可恢复路径
- 主题变量优先：新增颜色一律走 CSS 变量，保证明暗主题自动适配
- 动效克制：只用于状态反馈（busy/hover/active/数据变更），不加装饰性循环动画
