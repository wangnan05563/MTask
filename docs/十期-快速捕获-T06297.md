## 交付内容

### 1. 入口与快捷键

- `web/src/App.tsx` 顶栏新增 `Zap` 快速捕获按钮（`data-capture-open`），任何页面常驻。
- `Ctrl/Cmd+Shift+Space` 在 `App` 的全局 `keydown` 监听中处理：
  - 输入框内也放行（正在写东西时冒出一个想法，是这个快捷键的主场景）；
  - IME 组合中不抢键；
  - 打开捕获时关闭命令面板，避免两个浮层叠加。
- 实测唤起耗时 **55ms**（首页）/ **19ms**（任务页），均远低于 A5 的 1 秒要求。

### 2. 自然语言解析（单源模块）

`web/src/ui/quickCaptureParse.ts`：

| 标记 | 支持格式 | 落点 |
|---|---|---|
| `@日期` | 今天/明天/后天/大后天、周X/本周X/下周X/下下X、N天/周后、`YYYY-MM-DD`、`M月D日`、`M/D` | `dueDate`；因任务表无截止字段，保存时以 `⏰` 写进描述 |
| `!优先级` | 紧急/高/普通/中/低、`!P0`~`!P3`、urgent/high/normal/low | `priority` |
| `#项目` | 项目列表精确名称（大小写不敏感） | `projectId` |
| `/类型` | 现有任务分类精确名称；`/bug`、`/doc`、`/test` 等常用别名 | `categoryId` |

细节：

- 标记可被空格/中文标点分隔，也可紧跟正文（`修一下#MTask十期!紧急`）。
- 命中才从标题摘除；未命中（项目/类型不存在、日期非法）**原样留在标题**，同时 `unresolved` 回传 UI 提示，不静默吞字。
- 同一字段重复标记时后一个生效；全角 `！＃／＠` 同样识别。
- 日期全部按本地日历计算，不走 `toISOString`，避免东八区凌晨折到前一天。

### 3. 浮层与可编辑 chips

`web/src/ui/QuickCapture.tsx` + `quickCapture.css`：

- `Ctrl/Cmd+Shift+Space` 或顶栏按钮打开，输入框自动聚焦，关闭后焦点还给唤起处。
- 输入时实时解析，展示“将创建：标题”预览；四个字段以 `select/date` chip 展示：
  - 解析命中的 chip 高亮描边（`data-parsed=true`）；
  - chip 可直接改值；改值会把原文对应标记摘除，避免下一次输入又覆盖手选值；
  - 日期 chip 改值后仍复用同一套标签格式化。
- Enter 保存；Esc 空态直接关闭；有未保存内容时显示“继续编辑/丢弃”二次确认。
- 保存：复用 `POST /tasks`，写入 `title/description/priority/categoryId/projectId`；不新增后端字段、不改数据库。
- 保存成功：关闭浮层并弹 toast；toast 保留一次“撤销”，5.5 秒后自动消失。
- 撤销：调用 `POST /archive`，任务进入归档；active 列表不可见，归档页可恢复。**不做物理删除**。

### 4. 默认值

- 默认项目读 `/settings/note-project`（当前为 `收件箱`），项目/类型列表来自 `/projects`、`/task-categories`。
- 默认优先级 `normal`；未选类型不写 `categoryId`。

## 边界

- **不是 OS 全局热键**：仅在 MTask 窗口内生效；应用不在前台时的系统级热键需桌面主进程另单实现。
- **快捷键固定**：默认 `Ctrl/Cmd+Shift+Space` 已实现，自定义快捷键/冲突检测未进入本单。
- **不支持离线保存**：断网时保存失败会保留浮层内容并提示错误，但不会落本地草稿队列（任务单明确排除）。
- **类型复用分类**：`/类型` 落到现有 `categoryId`，没有新增独立“任务类型”字段。
- **日期只进描述**：任务表没有截止日期字段，`@日期` 以 `⏰` 写入描述；后续若加独立字段需迁移。
- **撤销=归档**：一次撤销让任务从 active 消失，同时保留归档可恢复；不是物理删除。
- **移动端未接入**：本单是桌面快捷键入口；移动端 QuickNote 仍是原有解析器，未切到本模块。
- **未识别标记不丢**：会保留在标题并在 UI 标红，保存时不会自动丢弃；这是有意行为，不是解析失败兜底删除。
