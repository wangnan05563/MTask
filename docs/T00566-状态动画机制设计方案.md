# T00566 设计方案：任务状态动画机制（运行中 / 运行失败 / 未读 / 已读）

> 参考交互原型：trae 消息读取机制（未读点提示 + 查看后消失）。图标样式与动效由本项目自定义。

## 1. 总体架构

Agent 处理任务的生命周期通过 **MCP 工具 `mtask_write_task_status`** 回写任务状态 → 服务端落库（tasks.ai_state）→ ChangeBus 推送前端刷新 → 任务编号前显示对应状态动画 → 用户点击查看任务详情后前端静默清空状态（已读隐藏）。

## 2. 状态机

```
(无/'') --Agent开始处理(running)--> running --Agent异常中断(failed)--> failed
running --Agent完成回写(unread)--> unread
failed --Agent重试开始(running)--> running
unread --用户点击查看(展开详情/处理结果)--> ''（图标隐藏）
```

约束：仅四种状态（running/failed/unread/'' 已读隐藏），不多不少；非法值由服务端忽略。

## 3. 服务端

### 3.1 数据库（server/src/db/schema.ts）
tasks 表新增列（ensureColumn 幂等迁移，老库自动补列）：
```sql
ai_state TEXT DEFAULT ''   -- '' 已读/无 | 'running' | 'failed' | 'unread'
```

### 3.2 TaskService（server/src/services/TaskService.ts）
- `TaskRow` / `TaskView` 接口新增 `ai_state: string`；rowToTask spread 透传
- update 白名单 Pick 加入 `ai_state`
- 新增便捷方法：
```ts
setAiState(id: string, state: string): TaskView | null
// allowed = {'running','failed','unread',''}；非法值直接返回现值（不写库）
```

### 3.3 REST（server/src/routes/index.ts）
`PATCH /tasks/:id` 载荷新增 `aiState`（camelCase）→ `ai_state`。

## 4. MCP 接口（server/src/mcp/server.ts）

新增工具 `mtask_write_task_status`：

| 参数 | 类型 | 说明 |
|---|---|---|
| taskNo | string（与 id 二选一） | 任务编号，如 T00566 |
| id | string（与 taskNo 二选一） | 任务内部 id |
| state | enum('running'\|'failed'\|'unread') | 目标状态 |

返回：`{ id, task_no, ai_state }`。已读（清空）由前端用户查看行为触发，不通过本工具。

## 5. mtask 技能（~/.workbuddy/skills/mtask）

生命周期状态回写锚点（config.yaml `ai-state.write-points`）：

| 时机 | 步骤锚点 | 回写 |
|---|---|---|
| Agent 开始处理 | 读取详情成功后（①a2） | `state: 'running'` |
| 自检失败 / 异常中断 | 步骤 ⑤ | `state: 'failed'` |
| 处理完成 | 闭环门 / 完成标注前（⑦b） | `state: 'unread'` |

脚本：`mcp-direct-call.py` 新增子命令 `status <taskNo> <state>`。

## 6. 前端（web/src/pages/TasksPage.tsx）

任务编号徽标**之前**渲染状态图标（`t.ai_state` 驱动）：

| 状态 | 图标 | 动画 | 颜色 |
|---|---|---|---|
| running | Loader2（lucide） | `.aispin` 旋转 0.8s infinite | var(--accent) |
| failed | AlertTriangle | `.ai-failed-pulse` scale 1→1.15 + 透明度脉动 1.1s | var(--danger) |
| unread | 实心圆点 8px | `.ai-unread-breathe` scale 1→1.35 呼吸 1.6s | var(--accent) |
| ''（已读/无） | 不渲染（隐藏） | — | — |

标记已读：展开任务描述 / 展开处理结果（查看行为）时，若 `ai_state === 'unread'` → 静默 `PATCH /tasks/{id} {aiState: ''}` + 本地 state 即时清空（不刷全表）。

## 7. 交互时序

```
AIAgent 调 MCP (running)  → 前端 ChangeBus 刷新 → 编号前转圈
AIAgent 异常中断 (failed) → 编号前红色警示脉动
AIAgent 完成 (unread)     → 编号前未读圆点呼吸
用户展开任务详情/结果     → 静默 PATCH 清空 → 图标消失
```
