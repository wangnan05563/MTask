# T03255 任务分类优先级建议（AI-203 ①⑤）

## 1. 范围与拆分

本单承接 AI-203「任务分类与优先级建议」中可独立交付的两条：

| 验收条 | 本单 | 承接单 |
|---|---|---|
| ① 新建/编辑可获取分类 + 优先级 + 一句理由 | ✅ | 本单 |
| ⑤ 用户确认前任务数据不变（不自动落库） | ✅ | 本单 |
| ② `suggestion_id` 记录 shown/accepted/dismissed/timeout 与采纳率 | — | T03256 |
| ③ 功能可关闭 | — | T03256 |
| ④ 未启用可隐藏 / 配置失效按 D-14 显示禁用原因 | — | T03257 |

建议本就是「只读 + 用户确认」，因此本单不建任何记录表；埋点/开关与「隐藏/禁用」分别在 T03256/T03257 叠加，避免在同一处反复改建议协议。

## 2. 与既有「智能分类」的关系

| 能力 | 入口 | 是否自动写库 | 输入 | 输出 |
|---|---|---|---|---|
| 既有智能分类（T00473） | 新建任务时静默执行 / 批量分类 | 是（创建或批量确认时写回） | 仅标题 | 分类 id + 优先级 |
| 本单建议（T03255） | 新建表单「✨」按钮 / 任务行「✨」按钮 | **否**（采纳前不写） | 标题 + 描述 + 同项目历史 | 分类 + 优先级 + 一句理由 |

既有自动分类路径保持原样，未改动其行为；本单是并列的显式建议通道，用于「先看理由再决定」。

## 3. 服务端

### 3.1 服务方法

`server/src/services/AIService.ts` 新增 `suggestTaskClassification(input, toolId)`：

- 输入：`title`、`description`、`projectId`、可选 `taskId`（编辑场景）、`categories[]`。
- 历史上下文：同项目 `archived = 0` 的最近 20 条任务（`title | 分类名 | 优先级`），**排除当前任务自身**——否则建议会拿自己当前分类自我强化。
- 提示词要求一行输出 `分类名|优先级字母|理由`；解析口径复用既有分类匹配规则（精确优先 → 最长名称包含），理由从第三个字段起整段保留（允许出现 `|`）。
- `NONE` → 分类为空；未知优先级字母 → `normal`；理由为空 → 「模型未给出理由」。
- 用量照常记 `ai_usage`：`kind=classify`、`card_key=ai.category_classify`，与既有分类共用同一卡片维度。
- 只读：不触碰 `tasks` 表。

### 3.2 路由

新文件 `server/src/routes/taskSuggest.ts`，`POST /api/tasks/classify-suggest`：

- 入参：`title`（必填）、`toolId`（必填）、`description`、`projectId`、`taskId`、`categories`。
- `taskId` 存在时从任务反查项目（前端传错项目也不会把历史参考串到别的项目）。
- `categories` 缺省时取服务端分类列表。
- 挂载点：`server/src/index.ts` 与主 `api` 路由同级（`accessTokenGuard + csrfGuard`）。

> 为什么不并进 `server/src/routes/index.ts`：该文件当时被并发 WIP 占用（sonarScan 两行），且建议面只读、与任务写入面分离后，验收门可以直接断言「调用前后任务行不变」。

## 4. 前端

`web/src/pages/TasksPage.tsx`：

- 新建表单：智能分类开关右侧新增「✨ 分类建议」按钮（`data-t03255="create-trigger"`）。点击后按标题 + 描述取建议，渲染建议条（`data-t03255="create-suggest"`）：`分类名｜优先级｜理由｜采纳｜不用`。
  - 采纳：只把分类/优先级填入表单下拉，**不建单**，提示「已填入建议 — 确认无误后再点击添加任务」。
  - 标题或描述一旦被修改，旧建议自动收起（避免建议与内容脱节）。
- 任务行：分类下拉右侧新增「✨」按钮（`data-t03255="row-trigger"`），建议条渲染在元信息行下方（`data-t03255="row-suggest"`）。
  - 采纳：用户点「采纳」后才 PATCH 该任务的分类与优先级（一键采纳语义），并提示「已采纳建议」。
  - 展示阶段任务行、列表与库均不变。
- 未配置整理工具时点按钮走既有 `aiBlockedFlash` 提示；接口失败把服务端 `error` 原文回显（模型未配置等）。
