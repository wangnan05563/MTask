# MTask 用户手册 · 十期版

- 适用版本：`0.1.1123.284`
- 适用对象：日常使用 MTask 管理任务、计划与 AI 执行的用户
- 在线帮助：应用内「设置 → 帮助文档」与本手册同源；冲突时以应用内实际界面为准
- 更新日志：[`docs/更新日志-十期.md`](更新日志-十期.md)

## 1. 安装与首次启动

1. 运行 `MTask Setup 0.1.1123.284.exe`，按向导完成安装；覆盖安装会保留用户数据。
2. 启动后确认顶栏显示「后端已连接」。桌面版默认使用 `39877` 端口；开发版为 `39876`。
3. 首次进入默认停在「今日」页。若没有项目，先在首页或任务页新建项目，再建第一条任务。

## 2. 今天先做什么

### 2.1 今日页

「今日」把当前最需要你出手的事压到一屏：

- 顶部四格：今天做 / 等我处理 / AI 正在跑 / 告警；
- 三组卡片：今日行动、等我处理、AI 正在跑；点任务直达任务抽屉，点 AI 卡片切到执行会话；
- 项目筛选在页头，切换项目即时刷新；
- 「项目统计」默认收起，点开才加载完整统计，避免拖慢首屏。

三组都为空时显示「今天还没有需要你出手的事」，可以直接去任务页建任务或去 AI 控制台发起执行。

### 2.2 收件箱

顶栏收件箱按钮的角标是 **open 事项数**，右下角小圆点才表示未读（`99+` 封顶）。快捷键 `Ctrl/Cmd+Shift+I` 直达。

- 分类：全部 / 待我决策 / AI 失败 / 待验证 / 系统；
- 有源任务：打开任务；无源任务：可「转任务」到指定项目；系统条目跳 AI 控制台；
- 「认领」只写处理人并保持 open；「忽略」进入终态；打开页面会清未读，但 open 角标只在事项真正解决后下降；
- 只收最近 90 天、非归档非搁置的事件；源事件恢复后旧条目会自动收敛，不会永久悬挂。

## 3. 任务处理闭环

### 3.1 建任务与处理

- 任务按项目组织，左侧选项目，右侧分「待办 / 已完成 / 搁置」；
- 新建任务标题必填，可填描述、优先级、分类、自定义字段，支持粘贴截图；
- 列表/看板随时切换；列表支持分页触底续载与窗口化，5k 任务下仍保持流畅；
- 展开行或详情抽屉可看描述、处理结果、AI 摘要、时间线、关联计划、Git、阻塞关系、自定义字段；
- 完成后可「标记验证失败」，填原因并附截图，任务自动回退待办；
- 「AI 美化」重排正文并保留语义；「AI 简化」把正文压成 ≤40 字标题（无正文时置灰）。

### 3.2 AI 状态

任务编号前的状态由接口驱动：

- 旋转：AI 正在处理（running）；
- 圆点：处理完成，待你查看（unread）；
- 红色警示：处理失败（failed）。

只有 `done + verified` 才算验证通过；未验证的完成会留在「未验证」清单，等待人工复核。

## 4. 搜索、视图、模板与导入

### 4.1 统一搜索（Ctrl/Cmd+K）

命令面板一次请求同时搜任务与 Run：

- 任务匹配标题、编号、正文、处理结果、AI 摘要；Run 匹配会话 ID、平台、阶段、关联任务；
- 排序：精确标题/编号 > 前缀 > 包含 > 最近更新；
- 支持 `type:task/run/all`、`status:`、`priority:`、`project:`；非法语法会降级全文并说明原因；
- ↑↓ 选择、Enter 执行；零结果给建议；归档 / 历史资产 / 搁置有命中时给三桶入口。

`Shift+F` 也可打开命令面板；`Ctrl/Cmd+F` 只聚焦当前页搜索框。输入框内与输入法组合中不抢 Shift+F。

### 4.2 保存视图

任务页视图切换右侧有「保存视图」：

- 保存当前视图类型（列表/看板）、关键词、分类、优先级、字段筛选、排序与密度；
- 可选择项目共享或私有；
- 选中立即应用；支持复制（重名自动加「（副本）」）与删除（只删配置，不动任务）；
- 当前状态写入 URL，刷新后恢复。

### 4.3 模板

工具条「模板」提供内置与自定义模板：

- 任务模板：在选中项目内生成一条任务；
- 项目模板：生成新项目与模板任务清单（最多 50 条任务）；
- 应用后可在实例记录中按实例撤销：任务实例走归档；项目实例若已被继续编辑（新增任务），整体撤销会被拒绝，避免误删；
- 任务模板不支持宏变量，模板 schema 即落库字段；内置模板不可改删。

### 4.4 导入

导入向导支持字段映射、预览（只读 dry-run）与失败回滚：

- 去重键为「来源 + 外部 ID」；同批次重复、改名重复、并发同键都会跳过；
- 无外部 ID 时回退按标题去重；
- 失败整批回滚，不会留下半条数据；
- 导入结果会报告新增/跳过条数。

## 5. AI 执行与人工审批

### 5.1 执行会话与 Run 追踪

「AI 控制台 → 执行会话」展示外部平台执行任务期间的会话：存活、停滞、已完成三态，以及阶段、进度、心跳与关联任务。停滞口径默认最近心跳超过 10 分钟。

点会话卡片「追踪」进入 Run 详情：

- 头部：状态、任务、项目、模型、Prompt 版本、耗时、Token、成本、审批状态；
- 步骤时间线：失败步骤默认展开，其余点击展开输入/输出/风险；
- 成本按步骤类型归因；旧会话无成本记录时显示「未记录成本」，不伪造 0 元；
- 运行中每 3 秒静默刷新，展开状态保留，页面隐藏时暂停。

### 5.2 人工审批

高风险动作会停在待审批状态。审批卡展示风险等级、动作、请求者、影响范围、diff、执行预览与剩余时间，填写备注后批准或拒绝。

- 风险级：R0 只读 / R1 可逆写 / R2 覆盖删除批量 / R3 外发部署权限不可逆；
- 项目策略默认：R0/R1 allow、R2 ask、R3 block；
- 批准后继续；拒绝则终止或回滚；
- 超时默认拒绝：Run 收口为 `failed/approval_timeout`，写 `expired` 审计，过期后不能再批；
- 决策写审计，可按 Run 查询。

## 6. 主题、无障碍与移动端

### 6.1 主题

设置 → 通用：

- 浅色 / 深色 / 跟随系统；
- 主题预设：默认浅色、默认深色、海洋、北欧、日暮、玫瑰；可再微调强调色；
- 字号档位与界面语言即时生效；语言包渐进覆盖，未覆盖页仍显示中文；
- 主题切换走语义 Token，不掉白、不闪屏。

### 6.2 无障碍

- 键盘 Tab 可达主导航与关键路径，焦点环 2px；
- 关键 10 页 axe WCAG 2 A/AA 无 serious/critical；
- 200% 缩放不横向滚动（页面布局按 1280 最小桌面宽度设计）。

### 6.3 移动端与离线

移动端按视口自动加载，也可用 `?m=1` 强制。底部 5 个 Tab：任务 / 随手记 / 队列 / 提示词 / 更多。

- 随手记 ≤3 步建任务，支持文本/语音/模板/图片；
- 断网提交失败自动存本地草稿，顶栏显示「离线」「待同步 N」；
- 恢复网络后自动 flush，成功即清零；
- 草稿只存本机，换设备或清浏览器数据会丢失。

## 7. 数据安全、备份与更新

### 7.1 日常备份

- 「设置 → 数据迁移」可导出单个 JSON 备份；导入支持合并 / 保留 / 覆盖三种策略；
- 覆盖导入会清空并替换全部数据，不可恢复；导入在单事务内完成，失败回滚；
- 升级安装包前建议先导出一份 JSON 备份。

维护者做整机迁移时，使用仓库内 `server/scripts/backup-data-package.mjs` 生成完整数据包（数据库 + 文件）；恢复时目标目录必须为空，工具会校验逐文件 SHA 与 SQLite integrity。T06318 已用 223MB 真实库完成「备份 → 空目录恢复 → 增量写入 → 二次备份 → 二次恢复」演练，迁移后标记数据完整往返；不覆盖损坏文件场景。

### 7.2 应用更新

入口：设置 → 关于 → 版本更新。填写发布仓库（私有仓库需只读 Token），保存后检查更新；发现新版本可下载安装包覆盖安装。下载中断支持续传。

## 8. 常见问题

**打开应用很慢？**
先确认数据库大小与磁盘状态；5k 任务基准下首屏约 0.6 秒。若明显变慢，检查是否同时跑了多个 AI 任务或磁盘占用过高。

**主题切换后仍有白底？**
确认页面是否使用了语义 Token；旧页面硬编码色已由 lint 拦截，遇到残留请截图反馈。

**AI 一直转圈？**
查看执行会话页是否有活跃会话；超过 10 分钟无心跳会判停滞。也可在任务详情看 AI 状态与失败原因。

**收件箱角标不减？**
角标统计 open 事项，不是未读。先完成事项动作（认领/忽略/转任务/源事件恢复），再回列表确认。

**审批超时了还能批准吗？**
不能。超时按默认拒绝收口，需重新发起新的审批。

**升级后数据会丢吗？**
覆盖安装保留用户数据；仍建议升级前备份。完整恢复要求空目录，避免覆盖现有数据。

## 9. 已知边界（十期）

- 日历视图、表格列宽拖拽、批量选择器仍属后续范围；
- 全局搜索当前覆盖任务与 Run，不覆盖独立 PRD 文档对象；
- 真实 CodeBuddy 网关、SonarQube 全量扫描与代码签名未在本期闭环；
- 高对比主题已有 Token 与测试验证，但设置页尚未暴露为用户可选档位；
- 性能数值来自 headless Chrome + SwiftShader 基准，真实 GPU/高刷屏可能更高。
