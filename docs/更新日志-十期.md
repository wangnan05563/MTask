## 本次更新重点

### 1. 今日首页（REQ-001 / §A1）

- 默认首页从统计仪表盘改为「今日」：四格摘要 + 今日行动 / 等我处理 / AI 正在跑三组卡片；
- 支持项目筛选、任务直达抽屉、AI 卡片跳执行会话；
- 项目统计改为按需展开，不再拖慢首屏；
- 5k 任务库首屏实测 619ms，聚合接口 18ms 级。

### 2. 可操作收件箱（REQ-032 / §A2）

- 新增顶栏收件箱入口与 `Ctrl/Cmd+Shift+I` 快捷键；
- 四分类：待我决策 / AI 失败 / 待验证 / 系统；
- 支持认领、忽略、转任务、打开源任务；
- open 角标与未读小圆点分离；90 天窗口、`event_key` 去重、源事件恢复自动收敛。

### 3. 统一搜索（REQ-003 / §A3）

- `Ctrl/Cmd+K` 一次请求统一搜任务与 Run；
- 任务覆盖标题/编号/正文/处理结果/AI 摘要，Run 覆盖会话/平台/阶段/关联任务；
- 精确 > 前缀 > 包含 > 最近更新排序；`type:/status:/priority:/project:` 语法；
- 180ms 防抖、迟到响应丢弃、零结果建议、归档/历史/搁置三桶入口；
- 1k 文档 100 次实测 P50 14.3ms / P95 18.3ms。

### 4. 保存视图与模板（REQ-009 / §B1、REQ-010 / §B2）

- 任务页可保存命名视图：视图类型、筛选、排序、密度；共享/私有、复制、删除；URL 刷新恢复；
- 模板支持任务模板与项目模板，卡片预览、一键实例化、按实例撤销；
- 项目实例被继续编辑后禁止整体撤销，避免误删；
- 导入向导支持字段映射、预览（只读 dry-run）、整批回滚与来源+外部 ID 去重。

### 5. Run 追踪与审批（REQ-036/§B6、REQ-007/§B7）

- 执行会话「追踪」进入 Run 详情：步骤时间线、风险、耗时、成本归因、失败步骤展开；
- 旧会话无成本时显示「未记录成本」，不伪造 0 元；
- 待审批卡展示风险、动作、影响范围、diff、执行预览、剩余时间；批准/拒绝写审计；
- 审批超时按默认拒绝收口：`failed/approval_timeout` + `expired` 审计，过期不可再批；
- 运行中 3 秒静默刷新，保留展开状态。

### 6. 主题、无障碍与离线

- 浅色 / 深色 / 跟随系统 + 6 套主题预设 + 强调色微调；
- 语义 Token 化，硬编码十六进制 lint 归零；`var(--warning)` 回退色一并清理；
- 关键 10 页 axe 浅色 15/15、深色 16/16，serious/critical 为 0；
- 移动端随手记支持断网本地草稿、恢复网络自动同步、待同步角标。

### 7. 性能与构建

- 5k 任务看板滚动 59.6fps，P95 帧间隔 16.8ms，>34ms 长帧 0；
- 主题切换四轮 30–31ms，均 ≤200ms；
- 前端按 vendor-react / vendor-graph / vendor-markdown / vendor-icons 拆包，文档基线构建主入口 2,091,371 B / gzip 601,154 B；
- 完整数据包备份/恢复演练通过：10 文件 / 223MB 真实库，SQLite integrity ok，恢复后任务/完成数/标记完整往返。

## 升级说明

1. 升级前在「设置 → 数据迁移」导出 JSON 备份；维护者另做完整数据包备份。
2. 运行 `MTask Setup 0.1.1123.284.exe` 覆盖安装，用户数据保留。
3. 首次启动检查「设置 → 帮助文档」是否显示本版更新；旧主题与草稿会保留。
4. 完整恢复必须使用空目录，工具会逐文件校验 SHA 并检查 SQLite integrity；不要覆盖现有数据目录。
5. 本期安装包未做代码签名，Windows SmartScreen 可能提示未知发布者。
