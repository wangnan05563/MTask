# T03622 项目管理工具栏按钮图标化

## 1. 结构

`web/src/pages/PlanPage.tsx` 工具条三处按钮由「图标 + 中文标签」改为「图标（+ 动态数字）」：

| 按钮 | 改前 | 改后 | 锚点 |
| --- | --- | --- | --- |
| AI 评估 | `Zap` + “AI 评估 3” | `Zap` + 数字 `3` | `data-t03622="eval"` / `data-t03622="eval-count"` |
| 补算复杂度 | `Gauge` + “补算复杂度” | `Gauge`（纯图标） | `data-t03622="complexity"` |
| 节假日 | 纯文本“节假日（2）” | `CalendarDays` + 数字 `2` | `data-t03622="holiday"` / `data-t03622="holiday-count"` |

数字口径：AI 评估 = `plans.length`（待评估计划条数），节假日 = `holidays.length`（已维护的节假日/加班日行数），
与原文本里的数字同源，未引入新取数。三处按钮统一 `padding: 6px 8px`，与工具条其它图标按钮同宽高。

## 2. 语义与可访问性

- 去掉可见文字后，语义全部由 `title` + `aria-label` 承载：
  - AI 评估 `aria-label="批量 AI 评估：N 条待评估"`；`title` 在原说明后补「（N 条待评估）」。
  - 补算复杂度 `aria-label="批量补算复杂度"`，原长说明（含 Shift 点击 = 连已评级重算）一字未改。
  - 节假日 `aria-label="节假日管理：已维护 N 条"`，`title` 同口径。
- **D-14 阻塞态不被覆盖**：AI 未就绪时 `title` 仍取 `aiBlockedTitle(...)`（阻塞原因与重试入口），
  只在非阻塞时拼「N 条待评估」，避免图标按钮丢失「为什么点不动」。
- 数字用 `fontVariantNumeric: tabular-nums`，评估中跟随刷新的条数不抖动；评估中改显进度标签
  `evalLabel`，评估结束回落为条数（与原 T01618 口径一致）。
