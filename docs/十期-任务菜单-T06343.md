# 十期 · 任务菜单布局重构（T06343）

## 结论

任务工具条已完成低频项收口：8 类低频入口统一收进「更多」面板，搜索框收缩到 160px 并改为常驻可见，模板入口移到「添加任务」按钮之前。1440/1280 标准宽度下工具条主排单行、无换行、无横向溢出；1024/760 允许换行但无溢出。保存视图、模板实例化、导入向导、T06342 页头精简均回归通过。

## 根因

`TasksPage.tsx` 的任务工具条是一个 `flex-wrap` 单排容器，原先同时承载项目切换、工作空间、排序、项目操作、分类、视图切换、多选、折叠、导入、搜索、模板、保存视图、密度、Git、导出/筛选等 20 余个控件。低频项虽然部分使用 `op-hidden` 悬浮显隐，但仍占用行宽，导致：

- 1280 及以下宽度时「更多」被挤到第二排，低频项反而占据主排；
- 搜索框固定 220px，且默认透明隐藏，首排出现不可见但占位的空白；
- 模板入口在工具条，添加任务按钮在新建任务行，两个高频入口分离；
- 工具条视觉层级不清晰，低频项与高频项混排。

## 影响范围

- 页面：任务页工具条、新建任务行；不涉及其他 10 个核心页的页头。
- 功能：保存视图、工作空间问答、AI 美化、行密度、Git 徽标、导出/筛选、项目操作入口的**位置**变化；交互逻辑、接口、数据语义未改。
- 兼容：More 面板常驻挂载、关闭时 `display:none`，保留既有测试对 `data-t06303="saved-view-menu"`、`data-t06305="template-menu"` 等 DOM 的定位能力。

## 修复

文件：`D:\code\otherProjects\MTask\web\src\pages\TasksPage.tsx`

1. `renderMorePanel()` 改为「低频操作与筛选」统一面板：
   - 新增保存视图组（选择/保存/复制/删除）、工作空间只读问答、AI 美化待办、列表行密度、Git 徽标；
   - 额外将项目新建/重命名/产品标签/删除 4 个项目管理动作移入面板（低频操作，释放首排 4 个图标宽度）；
   - 保留原有项目导出、分类/优先级筛选、自定义字段筛选与排序；
   - AI 不可用提示从主工具条移入面板，避免状态条独占首排；
   - `fieldset` 常驻挂载，展开时 `display:flex`、关闭时 `display:none`，用 `order:9 + flexBasis:100%` 独占末行。
2. 主工具条重构：
   - 移除保存视图、模板、AI 美化、工作空间问答、行密度、Git 徽标、项目操作按钮；
   - 搜索框 `maxWidth` 220 → 160，并去掉 `op-hidden`，让高频搜索入口常驻可见；
   - 「更多」入口 aria-label 改为「更多：低频操作与筛选」，展开/收起提示同步覆盖新增低频项；
   - 保留项目切换、工作空间选择、工作空间全文检索、项目排序、AI 批量分类、视图切换、多选、一键收起/展开、导入数据等主排操作。
3. 模板入口前置：`TemplateMenu` 从主工具条移到 `renderNewTaskForm()`，位于「添加任务」按钮之前；任务/项目实例化与撤销回调原样保留。
4. 新增可访问标识：`data-t06343="more-panel|saved-view|density|beautify|project-actions"`，便于回归与后续定位。

设计取舍：More 关闭时保留 DOM 而不卸载，是为了不破坏保存视图/模板历史回归脚本的 DOM 查询，同时避免组件内部状态因开关面板反复重置；视觉上通过 `display:none` 保证低频项不占首排、不产生空白。
