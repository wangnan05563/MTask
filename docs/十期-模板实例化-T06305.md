# 十期 · 模板实例化（T06305 / REQ-010 / PRD §B2）

## 结论

按 PRD §B2 交付模板最小闭环：**内置/自定义模板 → 卡片预览 → 一键实例化 → 按实例撤销**。任务模板在指定项目内生成单条任务；项目模板生成新项目及模板任务清单。**不支持宏变量**：模板 schema 即落库字段，实例化不做变量替换。

任务完成定义为「实例生成」，本单以实际建出的项目/任务与撤销结果为准；导入去重（AC-06）已由 T06304 独立满足，本单不重复实现。

## 实现

### 数据模型（`server/src/db/templateSchema.ts`）

- `templates(id, type, name, description, schema_json, version, builtin, created_at, updated_at)`，唯一索引 `(type, name)`；`type` 只允许 `task/project`。
- `template_instances(id, template_id, template_type, project_id, task_ids, created_at, undone_at)`：每次实例化留一条实例记录，`task_ids` 为 JSON 数组，撤销按实例精确回收。
- 内置种子：任务模板「功能开发任务」、项目模板「标准交付项目」（4 条任务：需求澄清与验收标准 / 方案设计与评审 / 开发与自测 / 验收与发布）。`INSERT ... ON CONFLICT DO NOTHING`，升级不覆盖用户副本。

### 服务规则（`server/src/services/TemplateService.ts`）

- CRUD：类型/名称/schema 校验；任务模板标题必填，优先级 `low/normal/high/urgent`、状态 `todo/done` 白名单；项目模板最多 50 条任务；schema ≤ 100KB；同类型重名 409；内置模板改/删 403。
- `instantiate`：单事务完成「建项目/任务 + 写实例」。
  - task：必须给 `projectId`，可选用 `title` 覆盖模板标题；目标项目不存在 404。
  - project：可指定项目名；显式重名 409，缺省用模板名并自动 `（2）` 避让；项目与任务一次落库，失败整体回滚。
- `undo`：
  - task 实例：归档本次创建的任务（不物理删，保留历史）。
  - project 实例：仅当项目内任务仍严格等于实例 `task_ids` 才允许删除项目；用户继续加过任务则 409「项目已被继续编辑（新增 N 条任务），不能整体撤销」，避免误删后续工作；删除前解除记忆的项目引用。
  - 重复撤销 409。

### REST（`server/src/routes/templates.ts`）

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/templates?type=` | 模板列表（可按类型过滤） |
| GET/POST/PATCH/DELETE | `/api/templates/:id` | 自定义模板 CRUD；内置只读 |
| POST | `/api/templates/:id/instantiate` | 一键实例化（task 传 `projectId`；project 可传 `name`） |
| GET | `/api/templates/instances?projectId=` | 实例记录 |
| GET | `/api/templates/instances/:instanceId` | 单实例详情 |
| POST | `/api/templates/instances/:instanceId/undo` | 撤销实例 |

静态 `/instances` 路由注册在 `/:id` 之前，避免被当成模板 id。

### 前端

- `web/src/components/TemplateMenu.tsx`：工具条「模板」入口。
  - 卡片预览：类型/内置标记、描述、将创建的字段（任务模板显示标题/优先级/状态与描述摘要；项目模板显示任务数与前 4 条任务名）。
  - 一键应用：任务模板要求当前选中具体项目，未选时按钮禁用并提示；项目模板创建后自动切换到新项目并立即拉取任务列表。
  - 成功态留在面板内展示创建结果与「撤销」按钮；项目已被继续编辑时原样回显 409 原因。
- `web/src/pages/TasksPage.tsx`：接入入口与回调（任务实例后刷新列表；项目实例后切项目 + 刷新项目列表；撤销项目后回退选择）。
- `web/src/api/client.ts`：新增 `Template/TemplateType/TemplateInstanceResult/TemplateUndoResult` 类型。

## 边界（本单未做）

- **无宏变量**：T06305 任务描述明确不支持；模板字段直接落库。
- **模板管理 UI**：本单完成定义是「一键实例化」，自定义模板的新建/改/删目前只走 REST；UI 能列出并应用已有自定义模板。若需要页面内编辑器，应另立任务。
- **项目实例撤销为保守策略**：项目被继续编辑后拒绝整体撤销，不提供强制删除入口。
- **未新增 MCP 工具**：模板能力当前仅 REST，未挂 `mtask_*` MCP 工具。
