# MTask 优化升级 — 需求规格说明书（SRS）

> 版本：v1.0（需求基线）　|　日期：2026-09-26　|　状态：需求规格基线（源自 7 产品竞品调研，见 `docs/竞品调研与优化需求梳理_2026-09-26.md`）
> 范围：MTask 桌面端 AI 任务开发管理工具的体验/功能/UI/主题/数据安全全面升级

---

## 1. 引言

### 1.1 目的
本文档定义 MTask 下一阶段优化升级的产品需求、验收准则与里程碑基线，作为设计、开发、验证的追踪来源。

### 1.2 范围
- **面向**：MTask 现有桌面端（Electron + React + Express + SQLite）。
- **In Scope**：客户体验提升、AI 任务编排功能扩展、UI 视图升级、主题体系升级、数据安全加固。
- **Out of Scope**：多用户协同 SaaS 化、移动端原生 App、非 SQLite 存储引擎替换。

### 1.3 术语
- **验证闭环**：AI 执行 → 结果回传 → 人工/自动验证 → 归并入库的既有流程。
- **需求矩阵**：prd_requirements（需求行）与 plan_tasks/tasks 经 req_ids 的多对多关联视图。

---

## 2. 总体描述

MTask 的差异化在「AI 任务闭环 + 验证纪律」（同类无产品做成一等公民）。本升级针对竞品对标发现的五处短板：通知缺失、效率交互薄弱、可观测深度不足、主题体系单薄、数据安全未加固。里程碑分三批：M1 体验地基（P0）→ M2 效率纵深（P1）→ M3 生态长尾（P2）。

---

## 3. 功能性需求

> 每条 FR 标注优先级（P0 必备 / P1 重要 / P2 增强）与验收准则。

### 3.1 客户体验提升（FR-1）

- **FR-1.1【P0】** 任务完成系统通知：AI 任务结束（unread/failed）时发 OS 级通知，点击跳转任务详情；托盘常驻。
  - *验收*：分发任务完成后 5s 内收到通知；点击通知定位到对应任务；托盘图标可开关。
- **FR-1.2【P0】** 失败一键重试：failed 任务提供「重试」，保留历次运行耗时与结果链（retry_of 溯源）。
  - *验收*：重试后原任务转 running；详情可展开历次尝试列表（时间/耗时/结果）。
- **FR-1.3【P0】** 下一个可执行任务推荐：按依赖图计算就绪任务，工作台置顶「现在做这个」卡片。
  - *验收*：无依赖或依赖均完成的任务被推荐；被推荐任务不重复出现在多个推荐位。
- **FR-1.4【P1】** 应用内通知中心：聚合「完成/待验证/需求变更」，支持已读未读与筛选。
  - *验收*：五类事件（完成/失败/待验证/矩阵变更/计划变更）入库并可筛选；未读数角标正确。
- **FR-1.5【P1】** 任务事件时间线：详情页展示状态流转、回传、验证历史（事件溯源）。
  - *验收*：一次任务生命周期产生 ≥4 条事件记录且按时间倒序展示；刷新不丢失。
- **FR-1.6【P1】** 批量操作：多选任务批量改状态/优先级/项目/归档。
  - *验收*：批量操作单事务落库；误操作可整批撤销（归档类除外）。
- **FR-1.7【P1】** 拖拽交互：任务卡拖拽排序、拖入状态列变更状态。
  - *验收*：拖拽落库后刷新顺序/状态保持；拖拽中不触发误变更。
- **FR-1.8【P1】** 命令面板增强：搜索任务内容、跳转矩阵、触发 AI 动作（周报/PRD 导入/分发）。
  - *验收*：面板可完成 5 类高频动作且 ≤2 次按键到达；搜索命中任务描述全文。
- **FR-1.9【P2】** 回传结果 diff 视图：文本/代码类回传与上一版对比渲染。
  - *验收*：两次回传可对比，增删行高亮。
- **FR-1.10【P2】** 空状态引导：首启动示例项目 + 任务模板 + 分步指引。
  - *验收*：新库首启动出现引导；一键生成示例项目（含依赖链三任务）。

### 3.2 功能扩展（FR-2）

- **FR-2.1【P0】** AI 复杂度分析：PRD 拆解后对每任务输出复杂度评级与工时校准，高复杂度标红并建议拆分。
  - *验收*：拆解结果含复杂度列；高复杂度任务在矩阵可见标红；一键建议拆分提示。
- **FR-2.2【P0】** 统计仪表盘：周吞吐、AI 成功率、平均耗时、验证通过率四卡 + 趋势图。
  - *验收*：四指标与库内数据一致（抽样核对）；支持按项目/时间过滤。
- **FR-2.3【P0】** 甘特/依赖图视图：deps 关系连线渲染 + 关键路径高亮。
  - *验收*：串行依赖以箭头连线展示；关键路径高亮；拖动节点联动日期。
- **FR-2.4【P0】** 验收准则字段化：任务级 acceptance 清单，验证时逐条勾选后方可置 verified。
  - *验收*：无 acceptance 的任务验证弹窗提示补录；未全勾选不可完成验证。
- **FR-2.5【P1】** 并行任务池：分发并发上限 + 队列排队 + 队列位次展示。
  - *验收*：超上限分发进入排队；位次实时更新；上限可配置。
- **FR-2.6【P1】** 单任务 AI 扩展：任意任务一键「展开为子任务」，子任务继承关联需求。
  - *验收*：展开产出 2-5 个子任务挂 parentId；req_ids 继承父任务。
- **FR-2.7【P1】** 任务→提交关联：记录任务产出 commit/PR 链接，详情直达。
  - *验收*：回传含 commit 时自动解析落库；点击可复制/打开。
- **FR-2.8【P1】** 标签与颜色：任务标签体系 + 色彩分类，支持跨项目筛选。
  - *验收*：标签可增删改查；筛选结果准确；颜色在列表/看板同步。
- **FR-2.9【P1】** PRD 双向锚点：需求行与 PRD 原文段落互相跳转高亮。
  - *验收*：矩阵行点击定位 PRD 源段落并高亮；PRD 段落可反查关联需求。
- **FR-2.10【P1】** 全文搜索：SQLite FTS5 索引任务/PRD/回传结果，命令面板深度搜索。
  - *验收*：万级记录搜索 <100ms；结果按相关度排序。
- **FR-2.11【P2】** 循环任务：周期性任务自动生成（如每周复核）。
  - *验收*：按周期规则自动建任务且不重复；可随时停用。
- **FR-2.12【P2】** API Token：为外部自动化发放只读/读写令牌，替代共享访问令牌。
  - *验收*：令牌可创建/吊销；只读令牌写操作被拒。

### 3.3 UI 升级（FR-3）

- **FR-3.1【P0】** 四视图切换器：列表/看板/时间线/矩阵一键切换，按项目记忆视图选择。
  - *验收*：四视图数据一致；切换 <300ms；刷新后保持上次视图。
- **FR-3.2【P0】** 任务详情侧滑面板：行点击右滑抽屉展示详情（回传/验证/图片内嵌），不离开列表。
  - *验收*：抽屉打开 <200ms；列表滚动位置保持；Esc 关闭。
- **FR-3.3【P1】** 骨架屏：列表/卡片加载态用 shimmer 骨架（与流光动画同一动效语言）。
  - *验收*：首屏加载出现骨架；数据到达后平滑过渡无跳动。
- **FR-3.4【P1】** 进出场动效：面板/卡片统一 zoom+fade 动效 token（150-200ms）。
  - *验收*：动效时长/曲线全局一致；低配机器可关闭。
- **FR-3.5【P1】** 密度切换：紧凑/舒适两档行高。
  - *验收*：切换即时生效并持久化；两档下均无文字截断。
- **FR-3.6【P1】** 虚拟滚动：千级任务列表滚动流畅。
  - *验收*：1000+ 任务滚动帧率稳定；快速滚动无白屏。
- **FR-3.7【P2】** 统一空态插画与行动按钮组件。
  - *验收*：五个以上页面空态使用统一组件。

### 3.4 主题升级（FR-4）

- **FR-4.1【P0】** 自定义强调色：accent 预设色板 + 取色器，全站变量联动。
  - *验收*：改色后全站即时生效并持久化；预设 ≥6 色。
- **FR-4.2【P0】** 跟随系统主题：明暗随 OS 自动切换。
  - *验收*：系统切换后 2s 内应用跟随；手动选择优先于跟随。
- **FR-4.3【P1】** 主题预设库：4-6 套完整预设（变量束一键切换）。
  - *验收*：预设含 accent/背景/代码块配套色；切换无残留旧色。
- **FR-4.4【P1】** 运行动画延展：流光体系扩展到进度条/骨架/按钮 loading。
  - *验收*：三类组件使用同一 keyframes；`prefers-reduced-motion` 下降级。
- **FR-4.5【P2】** 高对比度模式：无障碍对比度达标（WCAG AA）。
  - *验收*：高对比档全站文字对比度 ≥4.5:1；CI 加入对比度校验。

### 3.5 数据安全与工程（FR-5）

- **FR-5.1【P0】** 数据库自动备份：每日 SQLite online backup 快照，保留最近 N 份，设置页一键恢复。
  - *验收*：连续运行 3 天产生 3 份快照；恢复演练成功；备份失败有告警。
- **FR-5.2【P0】** 敏感字段加密：AI 工具 API Key 等敏感字段 AES-GCM 字段级加密落库。
  - *验收*：库内原始值不可读；读写透明兼容既有数据迁移；密钥本机保管。
- **FR-5.3【P2】** Markdown 全量导出：项目/任务/矩阵导出为人类可读 Markdown 报告。
  - *验收*：导出含矩阵关联关系；可独立阅读不依赖系统。
- **FR-5.4【P2】** i18n 框架：文案集中化，中文默认，预留英文包。
  - *验收*：核心页面文案走 i18n 词典；切换语言主要页面生效。

## 4. 非功能性需求（NFR）

- **性能**：列表/看板首屏 <500ms（千级任务）；搜索 <100ms；虚拟滚动 60fps。
- **可靠性**：备份/加密失败不阻塞主流程，有告警；批量操作事务化。
- **无障碍**：高对比档达 WCAG AA；动效尊重 `prefers-reduced-motion`。
- **兼容性**：Windows 10+；既有 312 条任务与全部历史数据无损迁移。
- **可扩展性**：动效/主题走 token 化变量；AI 动作注册表化（命令面板可插拔）。

## 5. 里程碑

- **M1 体验地基（约 4 周）**：P0 批次——系统通知、失败重试、next-task 推荐、复杂度分析、仪表盘、甘特依赖图、验收准则字段化、四视图、详情侧滑、accent 自定义、跟随系统主题、DB 自动备份、字段加密。
- **M2 效率纵深（约 6 周）**：P1 批次——通知中心、时间线、批量/拖拽、命令面板增强、并行队列、提交关联、标签、FTS、骨架屏/动效/密度/虚拟滚动、主题预设、流光延展。
- **M3 生态长尾（约 4 周）**：P2 批次——diff 视图、空态引导、循环任务、API token、Markdown 导出、高对比度、i18n、统一空态。
