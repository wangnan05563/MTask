# T03623 任务工具栏「更多」折叠

## 1. 结构

`web/src/pages/TasksPage.tsx` 的 `renderToolbar()`：

- **第一排（常驻）**：项目下拉、工作空间、全文检索、项目排序、项目操作、AI 美化/分类、视图切换、多选、一键收起/展开、导入数据、**更多**、Git 徽标、搜索。
- **第二排（「更多」内）**：导出项目、分类筛选、优先级筛选、自定义字段筛选（含条件/值/清除）、自定义字段排序。

「更多」按钮（`data-t03623="more-trigger"`，`MoreHorizontal` 图标，无文字）常驻第一排；点击展开
`data-t03623="more-panel"` 第二排（`order: 9` + `flexBasis: 100%`，独占工具条最后一行，宽度与工具条一致，
不挤压首排的 Git/搜索）。

## 2. 交互

- 默认收起：五件套只在展开时渲染（收起即不在 DOM，不留隐藏控件在首排）。
- 展开：按钮 `aria-expanded=true`、底色高亮。
- 收起：再次点击按钮 / 点击面板与按钮之外的区域（`mousedown` 捕获）/ `Esc`。
- 收起后若仍有筛选生效，按钮右上角显示计数徽标（`data-t03623="more-badge"`），避免「列表被筛空了却看不到原因」。
