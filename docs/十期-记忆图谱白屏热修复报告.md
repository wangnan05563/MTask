# 十期 · 记忆图谱白屏热修复报告

- 日期：2026-11-24

## 根因

`web/src/pages/MemoryGraph.tsx` 使用 `new Graph({ multi: false, type: 'undirected' })`。

`/api/memories/graph?productKey=mtask` 返回的边中，同一对记忆节点可能同时存在 `tag` 共享标签边和 `supersede` 替代链边。生产数据为 `nodes=141`、`edges=294`，其中 `tagEdgeCount=112`、`supersedeCount=14`；单边图第二次 `addEdgeWithKey` 抛错：

```text
Graph.addEdgeWithKey: an edge linking ... already exists
```

异常发生在 `useEffect` 内，旧版没有错误边界，React 根树被卸载，`#root` 为空、`body.innerText` 为空，表现为整页白屏。

## 修复

1. `MemoryGraph.tsx`
   - 改为 `new Graph({ multi: true, type: 'undirected' })`，保留 tag / supersede 平行边。
   - 增加 WebGL 2 预检 `supportsWebGL2()`；不可用时显示降级提示，不创建 Sigma。
   - Sigma 构造包 `try/catch`，失败时显示 `MemoryGraphFallback`。
2. `MemoryTab.tsx`
   - 新增 `MemoryGraphBoundary` 错误边界，包裹 `<MemoryGraph>`；单个图谱异常只降级图谱区域，不再卸载整个设置页/React 应用。
   - 通过 `onFallbackToList` 将「切回列表」接回 `setViewMode('list')`。

## 残余风险

- Sigma 4 需要 WebGL 2；远程桌面/软件渲染环境可能只能提供 WebGL 1，此时图谱会显示降级提示而非白屏。
- 目录加载方式可立即生效，但后续自动更新若覆盖 `resources`，需重新确认目录/asar 加载方式。
- 启动等待已放宽到 120 秒，冷启动极慢时会延长启动窗；这不是性能优化，只是避免后端被误杀。若后续能稳定复现 30 秒级冷启动，应继续定位 Electron 启动/维护队列的阻塞点。
- 本次未重打 `app.asar`，`asar pack` 两次未在可接受时间内产出；当前生产依赖目录加载。
