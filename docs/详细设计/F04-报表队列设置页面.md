# F04 报表 / 队列 / 设置页面

> 覆盖：`pages/ReportPage.tsx`、`pages/ReportConsole.tsx`、`reportStream.ts`、`pages/QueuePage.tsx`、`pages/SettingsPage.tsx` 及子视图（`ArchivePage`/`LogsPage`/`DbAdminTab`/`TunnelPanel`/`HelpTab`）、`pages/CommandPalette.tsx`
> 定位：周报生成 + AI 控制台、队列分发编辑、设置与全部子视图、全局命令面板。

---

## 1. ReportPage + ReportConsole + reportStream

**ReportPage**：周报生成——选周期(日/周/月)+格式(xlsx/docx/pdf/pptx)+项目+模板，生成下载；AI 流式周报（SSE）+ 右侧 `ReportConsole`；模板上传/管理。
- 端点：`GET /report/templates`、`POST /report/templates`、`DELETE /report/templates/:id`、`POST /report/generate`（下载）、`POST /report/ai-generate-stream`（SSE，经 `api/sse`）、`POST /report/ai-download`（token 下载读即删）；`GET /aitools` 模型列表。
- 依赖：`api/client`、`api/sse`、`reportStream`、`./ReportConsole`、`ui/session`。

**ReportConsole**：AI 分析控制台（嵌入 ReportPage）——预设类别（周期要点汇总/风险阻塞/改进建议/经验教训/提炼通用需求/自定义）对当前任务跑分析；管理 console-jobs（历史）、重启、删除、「提炼通用需求」→ `POST /ai/generalize-to-req`。
- 端点：`GET /console-jobs`、`POST /console-jobs`、`POST /console-jobs/:id/restart`、`DELETE /console-jobs/:id`、`DELETE /console-jobs`、`GET /req-categories`、`POST /ai/generalize-to-req`。
- 依赖：`api/client`、`ui/Markdown`、`ui/session`。

**reportStream.ts**：模块级单例，跨页面存活的 AI 周报流式状态（`useSyncExternalStore`）。导出 `reportStream`（`get/subscribe/begin/pushLog/appendText/setResult/finish`）、`useReportStream()`（`{streaming, logs, streamText, result}`）。切换页面期间保留进度/日志。

## 2. QueuePage — 队列分发编辑

**职责**：建当日队列、追加「任务+工具」Job、提交（轮询至完成）、重置、采纳 Job 回执为任务描述。
- 端点：`GET /queues`、`GET /tasks?archived=0`、`GET /aitools`、`GET /queues/:id`、`POST /queues {name,date}`、`POST /queues/:id/jobs {items:[{taskId,toolId}]}`、`POST /queues/:id/submit`、`POST /queues/:id/reset`、`POST /tasks/:task_id/adopt {content: response_payload}`。
- 依赖：`api/client`、`lucide-react`。（异步结果经后端 5s 轮询收口，前端轮询 `GET /queues/:id` 刷新状态。）

## 3. SettingsPage 及子视图

**SettingsPage**：设置 hub，`SUB_TABS`（通用设置/数据迁移/数据维护/任务分类/内网穿透/日志/归档/帮助文档/关于）。嵌入 `TunnelPanel`、`HelpTab`、`DbAdminTab`、`LogsPage`、`ArchivePage`。
- 端点（通用）：`GET/POST/PATCH/DELETE /task-categories`；迁移 `GET /settings/export`、`POST /settings/import {data, mode}`；更新 `GET /update/version|/update/config`、`POST /update/config`、`POST /update/test`、`POST /update/check`。
- 子视图各带自身端点（见对应文档）。

**ArchivePage**（设置→归档）：`GET /tasks?archived=1`、`GET /projects`、`GET /plans/archived`、`POST /archive/restore`、`DELETE /archive`、`POST /plans/:id/restore`、`DELETE /plans/:id`。

**LogsPage**（设置→日志）：`GET /logs?since=<seq>` 增量轮询；按级别着色、过滤、暂停、自动滚动。

**DbAdminTab**（设置→数据维护）：`GET /dbadmin/tables`、`GET /dbadmin/tables/:table`（行+total）、`DELETE /dbadmin/tables/:table/rows/:pk`、`POST /dbadmin/tables/:table/batch-delete {pks}`、`GET/POST /dbadmin/tables/:table/export|import`、`POST/PATCH /dbadmin/tables/:table/rows`。危险操作需确认码 `CONFIRM_DELETE`。

**TunnelPanel**（设置→内网穿透）：`GET/POST /tunnel/status|config`、`POST /tunnel/start|stop|reset-token`、`POST /tunnel/cloudflare/login`、`GET /tunnel/cloudflare/login/status`、`POST /tunnel/cloudflare/create|route-dns`。

**HelpTab**（设置→帮助文档）：静态数据驱动文档（功能说明/MCP 接口/配置样例/快速上手），详见「更新帮助文档菜单」任务。

## 4. CommandPalette — 全局命令面板（Ctrl/Cmd+K）

**职责**：跨实体搜索（任务/提示词）+ 页面跳转；↑↓ 选择、Enter 运行、Esc 关闭（`createPortal`）。
- 端点（打开时一次性拉取）：`GET /projects`、`GET /tasks?archived=0&limit=500`、`GET /prompts`。
- 分组：页面跳转（任务/提示词/队列）、任务搜索（title+task_no 模糊，选中复制任务号并跳任务页）、提示词搜索（title 模糊，跳提示词页）。
- 依赖：`api/client`、`react-dom`、`lucide-react`。

## 5. 依赖与边界

- 边界：报表为一次性文件读取即删；AI 周报严格基于真实聚合数据；DbAdmin 危险操作需确认码；Tunnel 端点自身放行令牌防锁死；命令面板仅在桌面端挂载（App.tsx）。
