# B07 提示词与通用需求模块

> 覆盖：`services/ReqService.ts`（`ReqCategoryService` + `ReqEntryService`）、`db/schema.ts`（表 `prompt_categories`/`prompts`/`req_categories`/`req_entries`）
> 定位：提示词仓库（FR-提示词库）与通用需求仓库（优秀实现/解决方案沉淀），均为「分类 + 条目」两级结构，可互相及向任务转化。

---

## 1. 提示词仓库（Prompt）

**表**：
- `prompt_categories`：id, name, description, sort_weight, builtin（内置分类不可删）, created_at, updated_at。
- `prompts`：id, category_id(FK CASCADE), title, content, pinned, created_at, updated_at。

**服务方法**（TaskCategoryService 同类模式）：
- `listPromptCategories()`（带 promptCount，5s 缓存）、`createPromptCategory`、`renamePromptCategory`、`removePromptCategory`（级联删 prompts）。
- `listPrompts(categoryId?, keyword?)`、`createPrompt`、`updatePrompt`（含 pinned）、`deletePrompt`、`toTask(id)`（一键转待办，落收件箱，去重）。

## 2. 通用需求仓库（Req）

**表**：
- `req_categories`：id, name, sort_weight, created_at, updated_at。
- `req_entries`：id, category_id(FK CASCADE), title, content, pinned, sort_weight, **fingerprint**（sha256(title+content) 前 24 位查重）, created_at, updated_at。

**服务方法**（`ReqService` 导出 `ReqCategoryService` / `ReqEntryService`）：
- `ReqCategoryService.list/create/rename/remove`（删除分类依赖 `ON DELETE CASCADE` 级联删条目）。
- `ReqEntryService.listByCategory/create/update/remove/existsByFingerprint`。
- `toTask(id)`：一键转待办（落收件箱，去重）；`toPlan(reqEntryId, projectId)`：转化为项目计划草稿（`POST /plans/from-req`）。

## 3. 查重与转化

- **指纹查重**：`existsByFingerprint(fp)` = `sha256(title+content)` 前 24 位；任务→提示词/需求、需求→提示词 等「复用/提炼」操作冲突返回 409，前端提示已存在。
- **互转链路**：
  - 任务 → 提示词（`POST /tasks/:id/to-prompt`）、任务 → 通用需求（`POST /tasks/:id/to-req`）
  - 提示词 → 任务（`POST /prompts/:id/to-task`）、通用需求 → 任务（`POST /req-entries/:id/to-task`）、通用需求 → 计划（`POST /plans/from-req`）
  - AI 控制台「提炼通用需求」（`POST /ai/generalize-to-req`，mode=ai|manual，指纹去重）

## 4. REST 边界

- 提示词：`GET/POST /prompt-categories`、`PATCH/DELETE /prompt-categories/:id`、`GET/POST /prompts`、`PATCH/DELETE /prompts/:id`、`POST /prompts/:id/to-task`
- 通用需求：`GET/POST /req-categories`、`PATCH/DELETE /req-categories/:id`、`GET/POST /req-entries`、`PATCH/DELETE /req-entries/:id`、`POST /req-entries/:id/to-task`
- 共享：`POST /tasks/:id/to-prompt`、`POST /tasks/:id/to-req`、`POST /plans/from-req`、`POST /ai/generalize-to-req`

## 5. 依赖与边界

- 依赖：`getDb`、`ChangeBus`、`crypto`（无）、`TaskService`（toTask 落收件箱）、`PlanService`（from-req）。
- 边界：删除分类级联删条目（CASCADE）；内置提示词分类 `builtin=1` 禁止删；`fingerprint` 查重防重复提炼/转存；pinned 置顶排序。
