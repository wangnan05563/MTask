# B03 任务与分类模块

> 覆盖：`services/TaskService.ts`、`services/TaskCategoryService.ts`、`services/TaskImageService.ts`、`services/ArchiveService.ts`
> 定位：任务全生命周期管理（CRUD / 编号 / 层级 / 排序 / 计划联动 / 资产复用）、分类、截图附件、归档。FR1 / FR5 / FR6。

---

## 1. TaskService — 任务核心服务

**职责**：任务 CRUD、编号分配、列表查询、父子两级层级、手动排序、计划联动、图片/需求/提示词资产复用。

**关键方法**：
- `list(opts)`：`TaskListOptions { projectId, archived, limit(≤500), offset, keyword, categoryId, sort }` → 分页/搜索/排序；含 plan 联动反查。
- `getById(id)` / `findByNo(taskNo)`：按 id 或 `T#####` 编号定位。
- `create(input)`：分配 `T`+5 位编号（`nextTaskNo()`），写 `tasks`；支持 `parentId` 两级层级（同项目校验）。
- `update(id, patch)`：字段更新（含 `parentId` 同项目校验，**禁止三级链**）；反向计划联动 + 父任务进度汇总。
- `reorder(orderedIds)`：写 `user_sort` 1..n（拖拽排序）。
- `moveProject(ids, pid)`：批量跨项目移动（单事务）。
- `setStatus(id, status)`：todo⇄done（FR5.1/5.3）。
- `reuse(id, projectId)`：复制任务（冲突 409）。
- `toPromptAsset(id, categoryId)` / `toReqAsset(id, categoryId)`：复制为提示词/通用需求资产（冲突 409）。
- `adoptContent(id, content)`：采纳 AI 文本 → 写 `ai_summary` 并置 done（FR4.4）。

**数据结构**：`TaskView` 随任务返回 `images` 元信息（不含 BLOB，批量查询避免 N+1）；`TaskInput` 入参（parentId 可选）。

**依赖**：`TaskImageService`、`ReqEntryService`、`ChangeBus`、`getDb`。

## 2. TaskCategoryService — 任务分类

**职责**：分类 CRUD；删除分类时其下任务 `category_id` 置空（保留任务）。

- 导出 `list / create / rename / remove`；`sort_weight` 排序。

## 3. TaskImageService — 任务截图附件

**职责**：图文混合描述，截图以 BLOB 落库（单文件可移植，随任务级联删）。

- 导出 `add / listByTask / getData / remove`；`MAX_IMAGE_BYTES = 8MB`（服务层校验，base64 膨胀约 4/3，故请求体上限 30mb）。
- `mapByTasks()` 按 ≤200 分批规避 SQLite 参数上限。
- 涉及表 `task_images`（task_id FK CASCADE）；`GET /images/:id` 直供 `<img>`。

## 4. ArchiveService — 归档/还原/删除

**职责**：`archived=1` 置位；仅已归档任务允许删除。

- 导出 `archive(taskIds)` / `restore(taskIds)` / `list` / `remove`（委托 TaskService 操作 `tasks.archived`）。
- 删除不可恢复，操作前由前端确认（FR6）。

---

## 核心流程

1. **创建任务**：`POST /tasks` → `TaskService.create`（补编号、可选 parentId）→ `notifyChange('tasks')` → 前端刷新。
2. **采纳回执**：队列页「采纳」→ `POST /tasks/:id/adopt {content}` → `adoptContent` 写 `ai_summary` + 置 done。
3. **归档删除**：`POST /archive {taskIds}` → `archived=1`；`DELETE /archive {taskIds}` 仅对 `archived=1` 生效。
4. **资产复用**：任务 → 提示词/通用需求/复制到其他项目，统一经 `toPromptAsset/toReqAsset/reuse`，冲突返回 409 由前端提示。

## 边界与异常处理

- **层级约束**：`parent_id` 仅两级，更新时禁止形成三级链（校验父任务本身无父）。
- **删除保护**：非归档任务不可删，删除前确认；图片随任务级联清理。
- **批量单事务**：`moveProject`/`batch` 操作在 `db.transaction` 内，失败回滚。
- **图片大小**：单图解码后 ≤8MB，超限拒绝并提示。
