# B09 数据维护模块

> 覆盖：`services/DbAdminService.ts`、`routes/dbadmin.ts`
> 定位：通用数据库表在线维护（管理员用），白名单校验表名/列名，防注入。设置 → 数据维护。

---

## 1. DbAdminService

**职责**：对任意业务表执行 CRUD / 批量删除 / 导入导出，表名列名白名单校验。

**关键方法**：`listTables` / `getColumns` / `pkColumn` / `listRows` / `insertRow` / `updateRow` / `deleteRow` / `batchDelete` / `importRows` / `exportRows`。

**安全约束**：
- 表名/列名正则 `^[\w]+$` 校验，阻断注入式名称。
- 写操作经 `db.transaction`；批量删除按主键数组；导入按行。

## 2. routes/dbadmin.ts — REST 边界

**统一错误包装**：`wrap()` → 400 + `{error}`。

| Method | Route | 用途 |
|--------|-------|------|
| GET | `/dbadmin/tables` | 列出表 |
| GET | `/dbadmin/tables/:table/schema` | 列定义 |
| GET | `/dbadmin/tables/:table/rows` | 行列表（分页） |
| POST | `/dbadmin/tables/:table/rows` | 插入 |
| PATCH | `/dbadmin/tables/:table/rows` | 更新 |
| DELETE | `/dbadmin/tables/:table/rows` | 删除 |
| POST | `/dbadmin/tables/:table/batch-delete` | 批量删除 |
| POST | `/dbadmin/tables/:table/import` | 导入行 |
| POST | `/dbadmin/tables/:table/export` | 导出行 |

**前端支持表**：projects / tasks / task_categories / task_images / ai_tools / queues / queue_jobs / prompt_categories / prompts / app_settings（DbAdminTab）。

## 3. 依赖与边界

- 依赖：`DbAdminService`、`getDb`。
- 边界：危险操作（删行/批删/导入覆盖）前端要求输入确认码 `CONFIRM_DELETE`；白名单防任意 SQL 表/列访问；不暴露系统表（sqlite_*/schema 内部）；图片 BLOB 以元信息展示，避免大体积拖慢列表。
