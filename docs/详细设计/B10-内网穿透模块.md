# B10 内网穿透模块

> 覆盖：`tunnel/tunnel-config.ts`、`tunnel/tunnel-service.ts`、`routes/tunnel.ts`
> 定位：将本地后端暴露到公网（Cloudflare / Cpolar / Tailscale），便于远程访问 API 或 Web；访问令牌保护公网接口。设置 → 内网穿透。

---

## 1. tunnel/tunnel-config.ts — 配置持久化

**职责**：穿透配置读写（JSON 文件 + 内存缓存）。

**导出**：`TunnelConfig` 接口、`loadTunnelConfig` / `saveTunnelConfig` / `saveTunnelField` / `backendPort` / `regenerateAccessToken`。

**关键字段**：`provider`、`backendPort`（本地 Express 端口 39876/39877）、`accessToken`（公网接口保护）、各 provider 凭据/隧道名等。

## 2. tunnel/tunnel-service.ts — 穿透编排（~1146 行）

**职责**：内网穿透编排。

**导出**：`TunnelProvider`（抽象基类）、`CloudflareProvider`、`CpolarProvider`、`TailscaleProvider`、`TunnelService`（门面）、`CloudflareLoginService`（命名隧道向导）；错误类 `BinaryDownloadError` / `TailscaleFunnelAuthError`。

**核心能力**：二进制下载/解压、进程拉起、隧道状态轮询、DNS 路由、访问令牌保护公网接口。

## 3. routes/tunnel.ts — REST 边界

**导出**：`router`（持有 `tunnel` 单例与 `getLoginService()`）。**自身放行 accessToken 校验**（否则用户无法在公网输入令牌解锁）。

| Method | Route | 用途 |
|--------|-------|------|
| GET | `/tunnel/status` | 当前穿透状态 |
| POST | `/tunnel/start` `/tunnel/stop` | 启停 |
| GET | `/tunnel/config` | 配置（`maskToken()` 脱敏） |
| POST | `/tunnel/config` | 保存配置 |
| POST | `/tunnel/reset-token` | 重置访问令牌 |
| POST | `/tunnel/cloudflare/login` | 启动 Cloudflare 登录 |
| GET | `/tunnel/cloudflare/login/status` | 登录态轮询 |
| POST | `/tunnel/cloudflare/create` | 创建隧道 |
| POST | `/tunnel/cloudflare/route-dns` | 配置 DNS 路由 |

## 4. 安全设计（与 index.ts 中间件联动）

- 一旦 `accessToken` 配置：除 `/tunnel/*`（隧道启停/配置自身）与 `/health` 外，**所有 `/api` 数据接口须携带 `X-Access-Token`**（`index.ts` 的 `accessTokenGuard`）。
- EventSource（`/api/events`）经 `?token=` 携带（与 `X-Access-Token` 同值）。未配置令牌（纯本地单机）整体放行，零回归。
- 打包版端口 `39877`、开发版 `39876`；App 启动读取 `/tunnel/config` 同步令牌到前端 `setAccessToken`。

## 5. 依赖与边界

- 依赖：`tunnel-config`、`child_process`、`fs`、网络下载；被 `index.ts` 挂载 `/api/tunnel`。
- 边界：隧道管理端点自身放行（防锁死）；`accessToken` 缺失时不强制（本地模式）；二进制下载失败抛 `BinaryDownloadError`；Tailscale Funnel 需交互授权，抛 `TailscaleFunnelAuthError` 由前端引导。
