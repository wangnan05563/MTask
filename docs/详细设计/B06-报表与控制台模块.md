# B06 报表与控制台模块

> 覆盖：`services/ReportService.ts`、`services/report-builder.ts`、`services/report-worker.ts`、`services/ConsoleJobService.ts`
> 定位：周期数据聚合 + 报表文件合成（Worker 池）+ 模板管理 + AI 周报；AI 控制台持久化并行任务。

---

## 1. ReportService — 聚合与编排

**职责**：周期数据聚合 + 报表合成调度 + 模板管理 + AI 周报。

**关键导出**：`gatherReportData`、`generateReport`、`aiGenerateReport`、`aiGenerateReportStream`、`listTemplates`、`saveTemplate`、`deleteTemplate`、`isReportToken`、`readAndDeleteReport`；类型 `ReportPeriod='day'|'week'|'month'`、`ReportFormat='xlsx'|'docx'|'pdf'|'pptx'`。

**核心流程**：
- `gatherReportData(period, projectId?)`：按 `updated_at` 落区间聚合任务（项目汇总 + 任务明细）→ `ReportData`；含计划执行情况（本期变动 + 过期未完成）。**只读、基于真实数据，不虚构**。
- `generateReport(period, format, opts)`：聚合 →（可选读模板 BLOB）→ `buildInWorker` → 返回 `{buffer, filename}`。
- `aiGenerateReport`：聚合 → `AIService.ask`（注入内置 SKILL 版式规范）→ 洞察正文 → `buildInWorker({aiInsight})` → 落临时文件 `reportTmpDir()` 返回 UUID `token`；可选把摘要推送到收件箱（`report.aiSummaryToInbox`）。
- `aiGenerateReportStream`：同上但 `AIService.askStream` + `onStage/onChunk` 回调供 SSE（`POST /report/ai-generate-stream`）。
- 模板：`templatesDir()`（`data/templates`，**磁盘当前为空**，由前端上传落盘）；`listTemplates`（仅 xlsx/docx，5s 缓存）、`saveTemplate`（≤10MB、安全字符校验、防路径穿越）、`deleteTemplate`。
- `isReportToken(token)`：UUID 正则防任意路径读；`readAndDeleteReport`：读即删（一次性文件）。

**依赖**：`AIService`、`getDb`、`AppSettings`、`worker_threads`、`exceljs/docx/pptxgenjs/pdfkit`（在 worker 内）。

## 2. report-builder.ts — 纯 CPU 合成

**职责**：被 worker 调用，按 `ReportData` + 可选 AI 洞察排版成对应格式。

- 导出 `buildXlsx / buildDocx / buildPptx / buildPdf`，签名 `(data, templateBuf?, aiInsight?) => Buffer`。
- xlsx/docx 支持用户上传模板 BLOB 覆盖版式；无模板用内置版式。

## 3. report-worker.ts — Worker 线程入口

**职责**：Worker Threads 入口，隔离报表合成 CPU。

- 消息协议：入参 `{format, data, templateBuf?, aiInsight?}` → 出参 `{buffer:Uint8Array}` 或 `{error:string}`；调用 `report-builder` 对应 `build*`。
- **串行构建**：单 Worker + `buildQueue`，`pump()` 串行投递，天然避免 CPU 竞争，主循环不阻塞。

## 4. ConsoleJobService — AI 控制台并行任务（T00417）

**职责**：AI 控制台持久化并行任务（预设分析类别：周期要点汇总/风险阻塞/改进建议/经验教训/提炼通用需求/自定义）。

- 导出 `create({title,prompt,category,period})`、`runJob(id, toolId)`（**不 await**，后台异步执行并 `markDone/markError` 回写库）、`list/get/reset/remove/clear`。
- 依赖：`AIService.ask`、`getDb`；表 `console_jobs`（status: busy/done/error，answer/error 文本）。
- 「提炼通用需求」→ `POST /ai/generalize-to-req`（mode=ai|manual，fingerprint 查重）。

## 5. REST 边界

- `POST /report/generate`（下载）、`GET /report/templates`、`POST /report/templates`、`DELETE /report/templates/:id`
- `POST /report/ai-generate`、`POST /report/ai-generate-stream`（SSE stage/chunk/done/error）、`POST /report/ai-download`（token 下载读即删）
- `POST /console-jobs`、`GET /console-jobs`、`POST /console-jobs/:id/restart`、`DELETE /console-jobs/:id`、`DELETE /console-jobs`、`POST /ai/generalize-to-req`

## 6. 边界与异常处理

- 报表为一次性文件，读取即删除（`readAndDeleteReport`）；token 用 UUID 正则防路径穿越。
- 模板上传 ≤10MB + 安全字符校验，防路径穿越与超大文件。
- AI 周报严格基于 `gatherReportData` 真实数据，不虚构；流式失败经 `error` 事件回传前端。
- Worker 串行队列，避免多报表并发 CPU 争用；合成异常回传 `{error}` 由主线程转 500/错误事件。
