# F05 移动端

> 覆盖：`mobile/MobileShell.tsx`、`mobile/MobileHome.tsx`、`mobile/QuickNote.tsx`、`mobile/MobileQueue.tsx`、`mobile/MobilePrompts.tsx`、`mobile/MobileMore.tsx`、`mobile/offline.ts`
> 定位：移动 Web 壳（底部 5 Tab + 随手记 + 离线草稿），与桌面共享同一 REST API；经 `App.tsx` `resolveUiMode()` 判定加载。

---

## 1. MobileShell — 移动壳

**职责**：底部 5 Tab 导航、顶部连接状态 + 离线草稿角标、访问令牌门、重连自动 flush 离线草稿、toast。

**移动导航 `TABS`**：home 任务(ListTodo)、note 随手记(Plus 中央 FAB)、queue 队列(ListOrdered)、prompts 提示词(ScrollText)、more 更多(MoreHorizontal)。

**端点**：`GET /health`（探测，返回 `unauthorized` → 令牌门）、`setAccessToken`、`flushDrafts()`（离线）。
**依赖**：`../api/client`、各 Mobile 子页、`./offline`。

## 2. MobileHome — 任务看板

**职责**：移动任务待办仪表盘——项目切换、待办列表、完成切换、展开详情（描述+图片）、下拉刷新、空态→QuickNote。
- 端点：`GET /tasks?projectId=`（前端过滤 status=todo）、`GET /task-categories`、`GET /projects`、`GET /settings/note-project`、`PATCH /tasks/:id`（状态切换）。

## 3. QuickNote — 随手记（核心捕获）

**职责**：≤3 步建任务（标题→完成）；支持文本、语音（Web Speech API）、模板（提示词预填）、图片附件；离线→本地草稿。
- 端点（经 `offline.submitQuickNote`）：`POST /tasks`、`POST /tasks/:id/images`（每张图）；并 `GET /projects`、`GET /task-categories`、`GET /settings/note-project`、`GET /prompts?keyword=`。
- 依赖：`./offline`（addDraft/submitQuickNote）、`lucide-react`。

## 4. offline.ts — 离线能力

**职责**：localStorage 草稿队列 + 在线状态 hook + 统一随手记提交（建任务 + 传图）。
- 导出：`QuickDraft` 接口、`loadDrafts/addDraft/removeDraft/clearDrafts`、`submitQuickNote(payload): Promise<Task>`、`flushDrafts(): Promise<number>`、`useOnlineStatus()`。
- `submitQuickNote` 内调 `POST /tasks` 后逐图 `POST /tasks/:id/images`；`flushDrafts` 重连时批量提交，返回成功数。

## 5. MobileQueue / MobilePrompts / MobileMore

- **MobileQueue**：队列只读——列队列、展开看每 Job 状态、复制 AI 回执；编辑引导桌面。`GET /queues`、`GET /tasks?archived=0`、`GET /queues/:id`。
- **MobilePrompts**：提示词库——分类→条目、展开看内容、复制全文。`GET /prompt-categories`、`GET /prompts?categoryId=`。
- **MobileMore**：低频聚合（只读）——配置记录 / 归档 / 周报(→桌面) / 日志 / 设置；`logout()` 清令牌。`GET /aitools`、`GET /tasks?archived=1`、`GET /logs`、`GET /tunnel/status`、`GET /projects`、`POST /settings/note-project`。

## 6. 依赖与边界

- 依赖：纯 `api/client` + `offline` + `settings`（主题）；无 Electron 专属 API。
- 边界：离线草稿存 localStorage，重连自动 flush；语音用 Web Speech API（依赖浏览器/系统支持）；令牌门在 `/health` 返回 `unauthorized` 时弹出输入；移动端只读模块（队列/配置/归档）编辑引导回桌面；图片附件走与桌面相同的 BLOB 落库路径。
