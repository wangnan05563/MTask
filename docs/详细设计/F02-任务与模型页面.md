# F02 任务与模型页面

> 覆盖：`pages/TasksPage.tsx`（122KB，核心页）、`pages/AIToolsPage.tsx`、`pages/UsagePanel.tsx`
> 定位：任务全生命周期管理与 AI 模型配置两大桌面主 Tab。

---

## 1. TasksPage — 任务管理中枢

**职责**：项目维度任务管理 hub——任务/项目/分类的增删改查；待办/完成双列表 + 搜索 + 分页 + 拖拽排序；AI 能力（标题美化/描述优化/智能分类）；CSV 批量导入；复用（复制到项目/提示词/需求）；归档/验证/优先级/置顶/截图粘贴；队列回执采纳。

**关键交互 → 端点**：
- 列表：`GET /tasks?projectId&archived&limit&keyword&categoryId`、`GET /task-categories`、`GET /projects`、`GET /settings/note-project`
- 写：`POST /tasks`、`PATCH /tasks/:id`、`POST /tasks/move`、`POST /tasks/reorder`、`POST /tasks/batch`、`POST /tasks/:id/reuse|to-prompt|to-req`、`POST /tasks/:id/adopt`、`DELETE`（经归档）
- AI：`POST /ai/beautify`（标题）、`POST /ai/optimize`（描述）、`POST /tasks/classify`（智能分类）、`POST /tasks/import-csv/preview|confirm`
- 附件：`POST /tasks/:id/images`、`GET /tasks/:id/images`、`DELETE /images/:id`（粘贴截图经 FileReader→dataURL→BLOB 落库）
- 实时：`api.openChangeStream('/api/events')` 订阅变更自动刷新

**状态持久化**：大量表单状态用 `useSessionState`/`usePersistentState`（半填输入跨 Tab 存活）；`beautifyStore` 管美化运行状态；`ui/busy` 防重复提交。

**依赖**：`api/client`、`stores/beautifyStore`、`ui/dialogs`、`ui/Markdown`、`ui/PinToggle`、`ui/session`、`ui/busy`。

## 2. AIToolsPage — 模型配置

**职责**：「模型」Tab——AI 工具 CRUD、启用/禁用、置顶、设默认 organize/develop、测试连接、拉取/刷新模型列表、密钥管理、拖拽排序；内嵌 `UsagePanel`。

**关键交互 → 端点**：
- `GET /aitools`、`GET /aitools/types`、`GET /aitools/defaults`
- 写：`POST /aitools`、`PATCH /aitools/:id`（编辑/启用/置顶）、`DELETE /aitools/:id`、`POST /aitools/reorder`
- 测试/模型：`POST /aitools/test`、`POST /aitools/models`、`POST /aitools/:id/test`、`POST /aitools/:id/models`、`GET /aitools/:id/api-key`、`POST /aitools/:id/set-default`

**依赖**：`api/client`、`./UsagePanel`、`ui/dialogs`、`ui/PinToggle`。

## 3. UsagePanel — AI 用量

**职责**：内嵌于 AIToolsPage 的用量统计——近 N 天调用概览、按工具分组、最近明细；可选 7/14/30/90 天。

- `GET /ai/usage?days=<n>`；导出 `UsageSummaryRow/UsageToolRow/UsageRecent/KIND_LABELS`。
- 依赖：`api/client`、`ui/format`。

## 4. 依赖与边界

- 边界：截图单图 ≤8MB（服务层校验，前端 Preview 前也提示）；标题美化经 `beautifyStore` 跨 Tab 保活；密钥界面仅脱敏（`GET /aitools/:id/api-key` 按需明文）；模型未配置时提交梳理会触发后端 `MODEL_UNCONFIGURED`，前端提示先配模型；CSV 导入先 preview 校验再 confirm（不入库预校验）。
- 这些页均为桌面主 Tab，经 `App.tsx` `TABS` 挂载。
