# F03 计划 / 提示词 / 需求页面

> 覆盖：`pages/PlanPage.tsx`、`pages/PromptsPage.tsx`、`pages/ReqPage.tsx`
> 定位：项目计划（甘特）、提示词仓库、通用需求仓库三个桌面主 Tab。

---

## 1. PlanPage — 项目计划（甘特）

**职责**：串行瀑布时间线 + 列表/甘特视图切换；计划任务增删改、关联待办、由计划建待办、归档/还原、节假日管理、Excel 导入/导出、AI 解析（文档→WBS 草稿）。

**关键交互 → 端点**：
- `GET /projects`、`GET /aitools`、`GET /plans?projectId=`
- 写：`POST /plans`、`PATCH /plans/:id`、`POST /plans/:id/archive`、`POST /plans/:id/restore`、`DELETE /plans/:id`、`POST /plans/:id/link {taskId|null}`、`POST /plans/:id/create-todo`、`POST /plans/reorder`
- 节假日：`GET /plans/holidays`、`POST /plans/holidays {date,name}`、`DELETE /plans/holidays/:date`、`POST /plans/holidays/import`（联网导入法定节假日）
- Excel：`GET /plans/template`（getBinary）、`GET /plans/export?projectId=`（getBinary）、`POST /plans/import`（postBinary）
- AI：`POST /plans/ai-parse`（Excel/CSV→草稿）、`POST /plans/ai-parse-doc`（Word/Markdown→WBS）、`POST /plans/batch`（批量确认）、`POST /plans/from-req {reqEntryId, projectId}`

**依赖**：`api/client`、`ui/dialogs`、`ui/session`。

## 2. PromptsPage — 提示词仓库

**职责**：分类 + 提示词 CRUD、搜索、排序、置顶、跨分类移动、复制、「转待办」（to-task）。

**关键交互 → 端点**：
- `GET /prompt-categories`、`POST /prompt-categories`、`PATCH /prompt-categories/:id`、`DELETE /prompt-categories/:id`
- `GET /prompts?categoryId=&keyword=`、`POST /prompts`、`PATCH /prompts/:id`（编辑/置顶/移动）、`DELETE /prompts/:id`、`POST /prompts/:id/to-task`

**依赖**：`api/client`、`ui/dialogs`、`ui/session`、`ui/Markdown`、`ui/PinToggle`、`ui/format`。

## 3. ReqPage — 通用需求仓库

**职责**：优秀实现/解决方案沉淀——分类 + 条目 CRUD、搜索、排序、置顶、移动、复制、「转待办」「转化为计划」。

**关键交互 → 端点**：
- `GET /req-categories`、`POST /req-categories`、`PATCH /req-categories/:id`、`DELETE /req-categories/:id`
- `GET /req-entries?categoryId=&keyword=`、`POST /req-entries`、`PATCH /req-entries/:id`（编辑/置顶/移动）、`DELETE /req-entries/:id`、`POST /req-entries/:id/to-task`、`POST /plans/from-req {reqEntryId, projectId}`

**依赖**：`api/client`、`ui/dialogs`、`ui/session`、`ui/Markdown`、`ui/PinToggle`、`ui/format`。

## 4. 依赖与边界

- 边界：计划增删改/节假日变更后后端事务内自动重排（前端无需算时间线，仅展示 `start_date/end_date`）；Excel 导入失败整体回滚，行级错误返回前端提示；AI 解析草稿需用户确认（`/plans/batch`）才落库；内置提示词分类 `builtin=1` 不可删；通用需求 `fingerprint` 查重，重复转存返回 409。
- 三页均为桌面主 Tab（项目计划/提示词/通用需求），经 `App.tsx` `TABS` 挂载。
