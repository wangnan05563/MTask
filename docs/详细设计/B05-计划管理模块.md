# B05 计划管理模块

> 覆盖：`services/PlanService.ts`（~817 行）、`routes/plans.ts`、`db/schema.ts`（表 `plan_tasks`、`holidays`）
> 定位：项目计划（甘特 / 串行瀑布时间线）全周期管理：重排、节假日、Excel 导入导出、AI 解析、关联待办。T00431。

---

## 1. 数据结构

- `plan_tasks`：id, project_id(FK), title, description, start_date, end_date, duration_days, progress, status(todo/doing/done/blocked), assignee, sort_order, linked_task_id, archived, archived_at。
- `holidays`：date(PK), name（工作日排除项）。
- `PlanStatus = 'todo' | 'doing' | 'done' | 'blocked'`。

## 2. 核心：串行瀑布时间线重排（state machine / 批处理）

- `isWorkday(d, holidays)`：非周六日且不在 `holidays`。
- `calcEndDate(start, durationDays, holidays)`：从 start 起数 `durationDays` 个工作日得 end。
- `nextWorkday(after, holidays)`：end 之后下一工作日。
- `rescheduleFrom(db, projectId, fromOrder, opts)`：从某 `sort_order` 起，**后续每行 start = 前置 end 的下一工作日**（跳过周末+节假日）；首行 start = `firstStartDate ?? afterEndDate 的下一工作日 ?? 自身 start_date`。end 冗余存储。
- `rescheduleAll` / `rescheduleAllProjects`：节假日变更后全量重排。
- 触发点：`create/update/archive/restore/reorder/insertAfter` 均在事务内触发重排。
- **计划↔待办双向同步**：`linkTodo` / `createLinkedTodo`（按 PlanStatus 映射 todo/done；任务置 done 时反向更新 plan status）。

## 3. 导入 / 导出（exceljs）

- `importExcel(projectId, buffer)`：逐行校验，失败整体不入库返回行级错误；首行用 startDate 作锚点，其余重排推导。
- `exportExcel` / `templateExcel`：sheet1 计划 + sheet2 节假日。
- `tableToTextAsync`（xlsx/csv→行文本）、`docxToMarkdown`（pizzip 解压 word/document.xml，标题样式转 `#`）。
- `aiParseWbs(toolId, docText)` / `aiParseDrafts(toolId, tableText)`：AI 拆 WBS，带 `parseJsonArrayWithRecovery`（截断补全，防 JSON 半截）。
- `importNationalHolidays(year)`：后端代理 timor.tech API，仅导入 `holiday=true`，upsert 幂等。
- `createFromReq`：通用需求 → 计划草稿（带 `[需求]` 前缀，查重）。

## 4. REST 边界（routes/plans.ts）

> 注意：节假日路由注册先于 `/:id`，避免被 `:id` 拦截。

- `GET/POST /plans/holidays`、`DELETE /plans/holidays/:date`、`POST /plans/holidays/import`（联网导入法定节假日）
- `GET /plans/template`（Excel 模板二进制）、`POST /plans/import`（Excel 二进制）、`GET /plans/export/:projectId`（导出二进制）
- `POST /plans/ai-parse`（Excel/CSV→文本→AI 解析草稿）、`POST /plans/ai-parse-doc`（Word/Markdown→WBS 拆分草稿）
- `POST /plans/batch`（批量确认创建）、`GET/POST /plans`、`GET /plans/archived`
- `GET/PATCH /plans/:id`、`DELETE /plans/:id`（归档软删）、`POST /plans/:id/archive`、`POST /plans/:id/restore`、`POST /plans/:id/purge`
- `POST /plans/from-req`（通用需求→计划草稿）、`POST /plans/reorder`（拖拽）、`POST /plans/:id/link`（关联待办）、`POST /plans/:id/create-todo`（由计划建关联待办）

## 5. 依赖与边界

- 依赖：`getDb`、`adapters`、`AIService`（AI 解析）、`TaskService`（关联待办联动）、`holidays`。
- 边界：重排在事务内保证一致性；Excel 导入失败整体回滚（行级错误返回前端）；节假日代理需外网（失败提示，不影响本地计划）；AI 解析带截断补全兜底，避免长输出导致 JSON 解析失败。
