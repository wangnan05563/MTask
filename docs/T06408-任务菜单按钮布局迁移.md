# T06408 任务菜单按钮布局迁移、分类与自适应

- 任务：T06408（MTask 十期）
- 仓库：`D:\code\otherProjects\MTask`
- 范围：仅任务菜单前端布局，不涉及后端结构与数据迁移

## 1. 实现结果

### 1.1 框架顶栏

- 新增 `ProjectSortButton`，放在 `ProjectSwitcher`（当前项目/工作区）之后。
- 项目排序偏好沿用 `tasks.projectSort`，新增共享状态 `useTasksProjectSort`；顶栏按钮与 `ProjectSwitcher` 同页即时同步，并继续跨会话持久化。
- `ProjectSwitcher` 的下拉列表按当前排序模式重排，「全部项目」始终置顶。
- 删除任务页原有的排序按钮、排序菜单状态及失效的项目下拉外部点击副作用。

### 1.2 主按钮栏

顺序调整为：

`日历视图 → 工作空间检索 → AI 批量分类 → 多选模式 → 收起/展开 → 资源提示 → 行尾组`

- 「工作空间检索」与「AI 批量分类」从低频隐藏控件改为常驻可见入口。
- 「AI 批量分类」在 AI 不可用或无任务时保留禁用态与原因提示。
- 搜索框与「更多」组成 `data-t06408="toolbar-tail"` 行尾组，使用 `margin-left: auto` 贴右；窄窗随整组换行，不产生横向滚动。

### 1.3 「更多」面板

面板改为纵向分类布局，四类各占一行，组间用分隔线区隔：

1. **视图**：保存视图、工作空间问答、AI 美化、行密度、Git 徽标
2. **项目**：工作空间下拉条 → 新建项目 → 重命名 → 产品标签 → 删除项目
3. **数据**：导出项目 → 导入数据
4. **筛选**：分类筛选、优先级筛选、自定义字段筛选/排序

关键位置已按要求落实：

- 工作空间下拉条位于「新项目」之前。
- 导入数据位于「导出项目」之后，并保留原文件选择与导入链路。
- AI 不可用提示保留在面板底部，不占分类行。

## 4. 边界说明

- 项目排序现在作用于框架顶栏的项目/工作区切换器；任务页自身没有独立项目列表，因此不再保留页面级排序菜单。
- 多选模式保留原有「悬浮显隐、进入多选后常驻」的交互，仅作为主按钮栏位置锚点，不改变其行为。
- 隔离实例未配置 AI 工具，浏览器探针验证了 AI 批量分类的位置、禁用态和原因提示；批量分类执行逻辑未改动。
- 导入数据验证了入口位置、文件输入保留与「更多」内可用性；未在探针中实际上传文件。
