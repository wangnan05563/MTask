# T06342 各页面移除重复面包屑及标题

- 项目：MTask 十期
- 任务：T06342「各页面移除重复面包屑及标题以释放正文空间」
- 日期：2026-11-25
- 分支：main
- 起始 HEAD：`3a249e525252a879a28bf03f119ac73e208003bd`

## 根因

`PageHeader` 把「面包屑 + 唯一 h1 + 说明」作为固定页头内容渲染；T06327 接入统一页面壳后，10 个核心页又各自传入 breadcrumbs、title 与 description。框架顶部标签已经显示当前页面名，页面正文再出现一层「工作台 / 任务」与同名的可见大标题，造成重复导航和垂直空间浪费。

本次不删除语义标题，而是把页头的「视觉 chrome」收掉：保留读屏可见的隐藏 h1 与页头操作槽，页面主内容直接上移。

## 影响范围

10 个核心页：

- 首页 `DashboardPage.tsx`
- 收件箱 `InboxPage.tsx`
- 任务 `TasksPage.tsx`
- AI 工具与模型 `AIToolsPage.tsx`
- 提示词 `PromptsPage.tsx`
- 通用需求 `ReqPage.tsx`
- 项目计划 `PlanPage.tsx`
- 投递队列 `QueuePage.tsx`
- 执行会话 `ExecSessionsPage.tsx`
- 设置 `SettingsPage.tsx`（仅非仪表盘子页）

保留项：

- 框架/侧栏/顶部标签、深链路由、刷新、搜索、筛选与页签切换全部不动；
- `PageHeader` 完整模式与面包屑组件保留，供未来需要显式层级导航的页面使用；
- 每页仍保留唯一一个 h1（隐藏），不影响读屏、SEO 与 T06327 的 SSR 契约；
- 有操作槽的页面（首页刷新/统计、收件箱新建、投递队列新建队列）继续保留页头按钮。

## 修复

1. `web/src/ui/layout/PageShell.tsx`
   - `PageHeaderProps` 新增 `minimal?: boolean`。
   - 抽出统一 `actions` 片段；`minimal` 分支只输出 `<header class="mt-page-header mt-page-header--minimal">`、读屏隐藏的 `<h1 class="mt-page-title-visually-hidden">` 与 `actions`，不再渲染面包屑、可见标题、说明。
   - 完整模式逻辑保持不变，T06327 SSR 契约不受影响。

2. `web/src/ui/layout/pageShell.css`
   - 新增 `.mt-page-header--minimal`：`padding: 8px 0 0`、`margin-bottom: 8px`、去掉底部分隔线，保留 8px 顶部呼吸位；有操作时靠右。
   - 新增 `.mt-page-title-visually-hidden`：1px 绝对定位裁剪，保留可访问文本。

3. 10 个页面接入
   - 每个 `PageHeader` 增加 `minimal`，删除 `breadcrumbs` 入参。
   - 保留原有 `description` 数据，但 minimal 模式不再视觉输出，避免无标题说明悬空。

4. 新增门禁与证据
   - `scripts/tests/verify-t06342-static.mjs`：10 页均启用 minimal、无 breadcrumbs 入参、无手写 h1；PageShell 完整面包屑语义未被误删。
   - `scripts/tests/verify-t06342-render.tsx`：minimal SSR 只输出 1 个隐藏 h1 + 操作槽，无面包屑/说明/可见标题类。
   - `scripts/tests/verify-t06342-visual.mjs`：10 页 × 1440/1280/1024/760 实测页头、可见标题、内容起点、操作槽与横向溢出。
