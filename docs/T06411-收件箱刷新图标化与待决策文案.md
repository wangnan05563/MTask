# T06411 收件箱刷新图标化右移，待决策文案及转入箭头优化

## 目标与结论

收件箱工具栏完成三项调整：刷新按钮去文字、仅保留图标并移到「转入项目」下拉条后方同排；「待我决策」全部改为「待决策」；「转入项目」增加自绘下拉箭头。浏览器探针 15/15 PASS，静态门禁 PASS，Web 构建通过。

## 实现

### 1. 刷新按钮图标化右移

- 移除 `PageHeader` 中的刷新 `primaryAction`；收件箱页头在 `minimal` 无操作时只保留读屏 `h1`，视觉上不再占一行。
- 在 `FilterBar` 行尾新增 `mt-inbox-target-group`，把「转入项目」与刷新按钮包成同一组：
  - 组 `margin-left: auto` 在 1440 贴右对齐；窄屏移除自动左推，但组内始终保持同排。
  - 刷新按钮 30×30、仅 `RefreshCw` 图标，无文字；`aria-label="刷新收件箱"`、`title="刷新"`。
  - `loading` 时禁用并旋转图标，点击继续调用 `fetchPage(0, false)`。

### 2. 文案替换

- `TYPE_META.decision.label`：`待我决策` → `待决策`。
- 收件箱页头描述与帮助页相关文案同步去除旧词，`web/src` 已无 `待我决策`。
- 计数键、筛选参数与业务逻辑不变。

### 3. 转入项目箭头

- `select` 关闭原生外观（`appearance: none`），外层 `mt-inbox-select` 定位。
- 右侧 `ChevronDown` 自绘箭头绝对定位、`pointer-events: none`，不拦截点击；保留 `padding-right: 28px` 避免文字压箭头。
