1. `web/vite.config.ts`
   - `build.rollupOptions.output.manualChunks`：按需拆分 `vendor-react`、`vendor-graph`、`vendor-markdown`、`vendor-icons`；主包不再吞下 graph/sigma 与 markdown 全量代码，浏览器可并行加载、二次启动命中缓存。
