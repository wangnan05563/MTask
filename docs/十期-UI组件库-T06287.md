## 3. API 摘要

### Button

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `variant` | `primary \| secondary \| ghost \| danger` | `secondary` | 语义变体 |
| `size` | `sm \| md \| lg` | `md` | 24 / 30 / 38px 高度 |
| `loading` | `boolean` | `false` | 禁用交互、`aria-busy`、显示 spinner |
| `loadingText` | `ReactNode` | children | loading 时可见文案 |
| `leftIcon` / `rightIcon` | `ReactNode` | — | 装饰图标，`aria-hidden` |
| `fullWidth` | `boolean` | `false` | 撑满容器 |

原生 `ButtonHTMLAttributes` 全部透传；`type` 默认 `button`。

### IconButton

`icon` + 必填 `label`。`label` 同时写入 `aria-label` 与 `title`，避免图标按钮无可读名称。

### Input

| Prop | 说明 |
| --- | --- |
| `label` | 自动关联 `htmlFor` / `id`；必填时显示星号 |
| `hint` | 写入 `aria-describedby` |
| `error` | 写入 `aria-invalid`、`aria-errormessage`、`aria-describedby`，错误文案 `role="alert"` |
| `prefix` / `suffix` | 前后缀节点，`aria-hidden` |
| `size` | `sm / md / lg`，26 / 30 / 40px |
| `disabled` / `readOnly` | 原生透传，容器同步 `data-disabled` / `data-readonly` |

### Table

| Prop | 说明 |
| --- | --- |
| `columns` | `{ key,title,render,width,align,className }[]` |
| `rows` | 泛型行数据 |
| `rowKey` | 行唯一键 |
| `density` | `compact / comfortable / loose` |
| `loading` / `loadingRows` | 骨架行，默认 4 行 |
| `emptyText` | 空态文案 |
| `selectedKey` | 受控选中行 |
| `onRowClick` | 行点击/Enter/Space 触发；不内置业务行为 |
| `ariaLabel` | 表格可访问名称 |

不提供排序、分页、筛选与行内编辑；这些属于业务表格层，后续在业务组件中组合。

### Card / Badge / Skeleton / EmptyState

- `Card`：`variant: default|muted|accent`、`padding: none|sm|md|lg`、`title`、`extra`。
- `Badge`：`tone: neutral|accent|success|warning|danger`、`size: sm|md`、`dot`。
- `Skeleton`：`width`、`height`、`rounded`，`aria-hidden`。
- `EmptyState`：`icon`、`title`、`hint`、`action: {label,onClick,variant,loading}`。

## 4. 状态矩阵

| 原语 | 默认 | hover | focus | disabled | 其他 |
| --- | --- | --- | --- | --- | --- |
| Button | 四种 variant | 背景/边框切换 | `:focus-visible` 焦点环 | 透明度 0.5 + 禁止光标 | loading：spinner + `aria-busy` |
| Input | component 边框/底 | — | `:focus-within` 焦点环 | 0.55 + 禁止光标 | invalid / readonly |
| Table | 表头/行/边框 | 行 hover | 行 `:focus-visible` 焦点环 | — | selected / loading / empty |
| Card | 卡片底/边框 | — | — | — | muted / accent |
| Badge | 五种语义色 | — | — | — | dot |
| Skeleton | pulse | — | — | — | reduced-motion 关闭动画 |
| EmptyState | 中性空态 | 按钮继承 Button | 按钮继承 Button | 按钮继承 Button | 可选 action |

## 5. Token 使用规则

组件颜色全部来自：

- `--mt-component-button-*`
- `--mt-component-input-*`
- `--mt-component-card-*`
- `--mt-component-table-*`
- `--mt-semantic-bg-* / text-* / border-* / status-* / accent-*`

组件与样式文件**禁止**出现 `#hex`，**禁止**直接引用 `--mt-primitive-*`。尺寸可使用 px 常量；颜色不得绕过 semantic/component 层。

## 6. 用法示例

```tsx
import { Button, Card, EmptyState, Input, Table, Badge } from './ui/components';

<Button variant="primary" loading={saving} loadingText="保存中" onClick={save}>
  保存
</Button>

<Input
  label="任务名称"
  hint="用于列表展示"
  error={nameError}
  value={name}
  onChange={(event) => setName(event.target.value)}
/>

<Card title="最近任务" extra={<Badge tone="accent">12</Badge>}>
  <Table
    ariaLabel="最近任务"
    columns={columns}
    rows={rows}
    rowKey={(row) => row.id}
    density="compact"
    emptyText="还没有任务"
  />
</Card>
```
