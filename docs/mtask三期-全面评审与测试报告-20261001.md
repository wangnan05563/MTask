## 一、代码评审（双域并行，子代理执行）

### 服务端（c9b8f9b..HEAD server/ 改动）
- **P0：0**；**P1：1**（系统性既有问题，非三期引入）——API 写操作无 CSRF/Origin 校验，
  `localStorage` 令牌使浏览器自动携带失效；隧道/本机单用户场景风险可控，
  建议另立专项（校验 Origin/Sec-Fetch-Site 头）
- **P2：8**（均一致性/健壮性）：setPaused/retryJob 缺 update 后 cacheClear 与 notifyChange、
  PushService.notify 表访问每次 ensureTable、export 无任务数上限、pause/retry 缺 HTTP 语义
  （204 vs 200 不一致）、TaskExportService 无事务快照、tunnel-config 双读竞态、export md 注入
  标题换行——**已修复其中 4 项低成本项**（见下），其余记录待办
- **结论：可放行**

  其余为改进建议记录：焦点管理、beforeinstallprompt、重复下载 API 合并等）
