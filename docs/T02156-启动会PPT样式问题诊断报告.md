# T02156 问题诊断报告：mtask 五期启动会 PPT 样式串行与背景缺陷

> 诊断对象：`C:\Users\hspcadmin\Desktop\项目启动会-mtask五期-20261014.pptx`（14 页，由「项目启动会 PPT 生成」功能产出）
> 参考基准：`F:\work\00-项目群管理\05-报告汇总\2023恒生PPT模板.pptx`
> 诊断方式：解包 OOXML 逐部件比对（slides/charts/theme/master/layouts），不依赖渲染器

## 一、问题清单（按严重度排序）

### P0-1 图表字体与正文「串行」：图表是 Arial，页面是微软雅黑
- 证据：`ppt/charts/chart1.xml` 全部 `typeface="Arial"`；正文/表格 1545 处 `typeface="微软雅黑"`。
- 影响：同一页里表格汉字是雅黑、图表刻度/图例/数据标签是 Arial，中西文混排下发虚、字重不一致，是最显眼的「样式串行」。

### P0-2 图表文字纯黑 `000000`，与页面墨色 `1F2937` 双轨并存
- 证据：chart1.xml 有 3 处 `srgbClr val="000000"`（轴标签/图例/数据标签默认色）；页面正文统一 `1F2937`。
- 影响：图表文字比页面文字「更黑更硬」，色彩体系割裂。

### P0-3 图表用色与品牌无关，且出现默认灰 `F9F9F9`
- 证据：chart1.xml 颜色只有 `3B5BDB`（报告系靛蓝）/`B42318`（报告系警示红）/`F9F9F9`（pptxgenjs 默认绘图区灰）。
- 影响：与恒生模板品牌蓝（`08409C`/`0059E9`）完全无关；浅灰绘图区在纯白页上发脏。

### P1-1 背景纯白、无任何版式资产
- 证据：slideMaster 无 `<p:bg>`，全部页面继承主题白；`ppt/media/` 为空（零图片）。
- 恒生模板对照：3 张 1920×1080 品牌背景（封面/目录/内容），浅蓝科技网格 + 立方体装饰 + HUNDSUN 标识。
- 影响：启动会是给客户/甲方看的第一面，纯白稿「视觉效果单调」，无品牌识别。

### P1-2 标题/表格/图形无品牌色层级
- 证据：标题 `1F2937` 墨黑 22pt；表头浅靛蓝 `EAF2FF` + 墨字；时间线条 `3B5BDB`、里程碑菱形 `B42318` 警示红。
- 恒生模板对照：标题/装饰统一 `08409C` 深蓝 + `0059E9` 亮蓝，无红色系。
- 影响：色系是「内部报表风」而非「企业品牌风」；里程碑用警示红与「达成」语义相反（库里 6 个里程碑全部 done，却画成红色）。

### P2-1 工作量页原始浮点直出
- 证据：第 10 页「报价区间：P50 42 / P84 **43.020620726159656** 人天」「阶段分布：req **1.0833333333333333** / …」。
- 影响：客户会上被追问「43.02 怎么来的」无法解释；呈现层未对派生量取整。

### P2-2 目录页无品牌装饰结构
- 恒生模板目录页有「目录」60pt 大标题 + CONTENTS 20pt + 蓝色小矩形下划线 + 圆角矩形装饰；本稿目录页只有 22pt 标题 + 4 行 14pt 条目。

### 观察项（非本单范围，记录备查）
- 第 13/14 页（沟通机制/资料清单）dataKeys 重复命中 preflight，两页表格几乎一致——AI 大纲编排层现象，需在大纲提示词层治理。
- pptxgenjs 对 doughnut/pie 图表的 `dLbls` 组级兜底块硬编码 Arial/18pt/黑（逐点 `<c:dLbl>` 可覆盖，实际渲染不受影响，但 XML 里有残留）。

## 二、根因归纳

| 现象 | 根因 | 层级 |
| --- | --- | --- |
| 图表字体/颜色串行 | `drawBlock` 的 addChart 只设了 chartColors，未声明轴/图例/数据标签的 fontFace 与 color，落到 pptxgenjs 默认 Arial+黑 | 装配层 |
| 背景纯白 | 生成器从不设置背景，master 无 `<p:bg>`；恒生模板的视觉资产（背景图）从未被引入 | 装配层 + 资产缺失 |
| 色系非品牌 | 色值单源 `exportStyle.ts` 只有「规范 A」报表色（靛蓝/警示红），无恒生品牌色常量 | 色值单源 |
| 浮点直出 | 派生量（P84、阶段人天）从估算引擎原值进模板字符串，无呈现层取整 | 装配层 |
| PRD N1 搁置模板 | 「不做 .pptx 母版/模板文件套用」的根因是装机版无 Python 运行时读模板母版——但 pptxgenjs 原生支持版式背景图，该约束可绕过 | 方案层 |

## 三、结论

样式串行不是「某页排坏了」，而是**生成器从未建立品牌设计系统**：字体只管了正文不管图表，颜色只继承了内部报表规范，背景层完全空缺。修复必须落在「色值单源 + 装配层显式声明 + 模板背景资产」三处，而不是逐页打补丁。
