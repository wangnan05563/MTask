# PPT Outline

## Overview
本培训 PPT 面向 MTask 新成员与协作方，系统讲解产品**四期、五期**交付的功能模块。四期上线「估算视图与工作量评估导出」与「测试用例管理（需求矩阵关联 + AI 生成）」两大模块；五期上线「AI 控制台 · 项目启动会 PPT 生成」模块。全篇以"资料沉淀 → 对外报价 → 一键成稿"的闭环为主线，帮助读者理解各模块的能力边界、技术实现与用法。共 21 页，采用科技风（tech）深色模板。

## Outline Content

### 第一章 背景与总览
- 封面：MTask 四期·五期 功能模块培训
- 目录：四章导航
- 过渡：01 背景与总览
- 背景与痛点：报价脱节 / 用例零散 / 资料不转化（含现状证据数据）
- 四期·五期 交付总览：三大能力模块地图（估算 / 导出 / 测试 / 启动会 PPT）

### 第二章 四期详解
- 过渡：02 四期详解
- 估算面板与三点估算：入口 / 面板 / 录入 / 可视化

- 测试用例管理模块：数据模型 / CRUD 批量 / 覆盖度 / 矩阵跳转
- AI 生成链路与 MCP：PRD→生成服务→草稿→确认导入→MCP 工具

### 第三章 五期详解

### 第四章 实操与收尾
- 过渡：04 实操与收尾
