> 面向所有用户的图文操作指引。功能位置：**设置 → 关于 → 版本更新**。

## 二、三步完成首次配置

### 第 1 步：填仓库地址

打开 **设置 → 关于**，滚动到「版本更新」卡片，在「仓库地址」填入你的发布仓库，例如：

```
mtask-dev/mtask
```

或完整网址 `https://github.com/mtask-dev/mtask`，两种写法都可以。

> 使用的仓库是**公开**的，跳过第 2 步，直接保存。

### 第 2 步（仅私有仓库）：填访问令牌

私有仓库需要粘贴一个 GitHub Token 才能读取版本信息：

1. GitHub 网页右上角头像 → **Settings** → 左侧底部 **Developer settings**；
2. **Personal access tokens → Fine-grained tokens → Generate new token**；
3. 勾选目标仓库，**Contents 权限设为 Read-only**（只读即可，不要给写权限）；
4. 生成后复制令牌，粘贴到应用的「访问令牌」输入框。

> 🔒 令牌在应用内**加密保存**、密码框掩码显示，任何界面都不会回显明文，可放心填写。

### 第 3 步：保存并检查

点击 **「保存配置」**（建议先点 **「测试连接」** 验证一下，成功会显示最新版本号），然后点 **「检查更新」**：

- **已是最新** → 提示「当前已是最新版本」，无需任何操作；
- **有新版本** → 显示绿色提示卡片，包含新版本号、发布时间、更新日志。

---

## 三、如何升级到新版本

1. 在新版本卡片中点击 **「下载新版本」**，浏览器/系统会下载 Windows 安装包；
2. 关闭正在运行的 MTask 程序；
3. 双击运行下载的安装包（如 `MTask-setup-x.x.x.exe`），按提示完成安装（覆盖安装，**用户数据自动保留**）；
4. 重新打开应用，「关于」页版本号即为新版本。

> 想先看看改了什么？点 **「查看发布页」** 可以在 GitHub 上浏览完整的更新说明。

## 四、常见问题

**Q1：点「检查更新」提示"尚未配置 GitHub 仓库"？**
先填仓库地址并点「保存配置」。

**Q2：提示"仓库不存在，或尚未发布任何 Release"？**
检查仓库地址拼写；若仓库确实存在，说明还没在 GitHub 发布 Release，联系发布者或等待发布。

**Q3：提示"认证凭据无效（401）"？**
Token 填错或已过期，重新生成一个并粘贴到「访问令牌」，点保存。

**Q4：提示"请求被限流（403）"？**
GitHub 对未认证请求限制较多，等一会儿再试，或按上面第 2 步配置 Token（额度大幅提升）。

**Q5：提示"连接 GitHub 超时"？**
检查电脑网络；如公司网络需要代理，请先配置系统代理再重试。

**Q6：换了 Token / 换了仓库，为什么检查结果还是旧的？**
请确认修改后**点击了「保存配置」**——保存会立即清空旧的检查缓存。

## 五、一句话总结

> **填仓库 → （私有仓库加 Token）→ 保存 → 检查更新 → 有新版就下载覆盖安装。**
