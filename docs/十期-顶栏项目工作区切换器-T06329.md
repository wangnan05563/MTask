## 2. 实现说明

### 2.1 全局项目上下文

新增 `web/src/ui/activeProject.ts`：

- `ACTIVE_PROJECT_KEY = 'tasks.activeProject'`：沿用旧键，升级不丢用户选择。
- `ALL_PROJECTS = '__all__'`：任务页沿用的「全部项目」哨兵；全局对外统一用空串，入任务页时映射，避免两套语义。
- `getActiveProject()` / `setActiveProject()`：读写内存快照与 `localStorage`；localStorage 不可用时降级为会话内生效。
- `useActiveProject()`：`useSyncExternalStore` 订阅，任务/计划/需求/队列/报表拿到同一份值。
- `activeProjectLabel()`：空串→「全部项目」；项目存在→项目名；项目已删→「项目已删除」，不冒充全部。
- 监听 `storage` 事件，多窗口/多标签同步。

### 2.2 顶栏切换器

新增 `web/src/ui/nav/ProjectSwitcher.tsx`：

- 取数走既有 `useProjectList({ excludeInbox: true })`，复用加载中/失败/重试语义。
- 选项为「全部项目」+ 真实项目；当前项 `aria-selected` 并显示勾选。
- 展开后焦点落到当前项；方向键循环移动，Enter/Space 选中，Esc/外部点击关闭并回焦。
- 图标改为内联 SVG，避免为三个图标引入额外依赖。
- 样式追加在 `web/src/ui/nav/primaryNav.css`：按钮最大宽 210px（1180 以下 160、960 以下 120），菜单绝对定位、限高 320px，颜色全部走主题变量。

### 2.3 页面消费

| 页面 | 接入方式 | 行为 |
|---|---|---|
| 任务 `TasksPage` | 删除本地 `activeProject` 持久状态，改为 `useActiveProject`；写入时把 `''` 映射为 `__all__` | 顶栏切换即过滤任务；原 8 处 `setActiveProject` 调用保持不变 |
| 项目计划 `PlanPage` | `projectId = globalProject \|\| sessionProjectId`；页面内换项目时写回全局 | 顶栏选项目后计划选择器同步；计划页内切项目会同步顶栏 |
| 通用需求 `ReqPage` | `currentProject` 改读全局值 | 「转计划」的默认目标项目跟随顶栏 |
| 投递队列 `QueuePage` | `projectId/setProjectId` 直接绑定全局 | 编排区筛选与顶栏双向同步，切换后重取任务 |
| 报表 `ReportPage` | 订阅全局值；顶栏变化时同步 `projectIds` | 选项目→范围变为单项目；切回全部→清空多选，回到全量聚合；首次进入且无范围时自动套用全局项目 |

## 4. 已知边界

- 计划页是单项目工作区，没有跨项目计划聚合视图：顶栏选择具体项目时完全同步；顶栏切到「全部项目」时，计划页沿用该页会话内上次项目，避免空表，属于本任务不改页面信息架构的取舍。
- 报表多选若由用户手工勾选多个项目，顶栏不发生切换时保持多选；一旦从顶栏切换项目，会按顶栏作用域收敛为单项目/全量。
- 切换器不处理移动端布局；移动端入口仍走既有移动导航。
- 项目删除后全局值保留并显示「项目已删除」，不静默回退到全部，用户可手动重选。
