# 版本更新功能 — 测试用例清单

> 对应功能：设置 → 关于 → 「版本更新」模块
>
> 覆盖范围：配置管理、连通性测试、版本检查（成功/失败场景）、安全与回归。
>
> 前置说明：TC-U-01x 为配置类用例；TC-U-02x 为检查更新用例；TC-U-03x 为错误处理；TC-U-04x 为安全与回归。

---

## 一、配置管理（TC-U-01x）

| 用例编号 | 场景 | 操作步骤 | 预期结果 | 类型 |
| --- | --- | --- | --- | --- |
| TC-U-011 | 保存公开仓库地址 | 输入 `owner/repo`（公开仓库）→ 保存配置 | 提示「配置已保存」；刷新页面后仓库地址回显 | 成功 |
| TC-U-012 | 保存完整 URL 格式地址 | 输入 `https://github.com/owner/repo` → 保存 | 保存成功；回显为规范化后的 `owner/repo` | 成功 |
| TC-U-013 | 保存 `.git` 后缀地址 | 输入 `https://github.com/owner/repo.git` → 保存 | 保存成功；回显去 `.git` 后的 `owner/repo` | 成功 |
| TC-U-014 | 非法仓库地址 | 输入 `abc` / 空格 / `github.com`（无仓库段）→ 保存 | 保存按钮拦截或返回「仓库地址非法」；配置不变 | 失败 |
| TC-U-015 | 保存私有仓库 Token | 输入有效 Token → 保存 | 保存成功；Token 输入框清空，placeholder 显示掩码 | 成功 |
| TC-U-016 | Token 留空保存 | 已有 Token 情况下 Token 框留空 → 保存 | 原 Token 保持不变（「留空表示不修改」语义） | 成功 |
| TC-U-017 | 修改后重测生效 | 更换仓库地址 → 保存 → 立即检查更新 | 检查走新仓库（配置保存会清除结果缓存） | 成功 |
| TC-U-018 | 配置持久化 | 保存配置 → 重启应用 → 打开关于页 | 仓库地址与 Token 配置状态均保留 | 成功 |

## 三、检查更新（TC-U-03x）

| 用例编号 | 场景 | 操作步骤 | 预期结果 | 类型 |
| --- | --- | --- | --- | --- |
| TC-U-031 | 有新版本 | 远端 Release `v(current+0.0.1)` → 检查更新 | 绿色卡片：发现新版本、发布时间、更新日志、下载/发布页按钮 | 成功 |
| TC-U-032 | 已是最新 | 远端最新 = 当前版本 → 检查更新 | 提示「当前已是最新版本：v\<当前\>（远端最新 v\<当前\>）」 | 成功 |
| TC-U-033 | 远端更旧 | 远端版本号小于当前 → 检查更新 | 同「已是最新」提示，不误报更新 | 成功 |
| TC-U-034 | 版本段数不等 | 远端 `v0.2`，当前 `0.2.0` → 检查更新 | 判定相等 → 「已是最新」 | 成功 |
| TC-U-035 | 数值比较正确性 | 远端 `v0.1.10`，当前 `0.1.9` → 检查更新 | 判定有更新（验证数值而非字符串比较） | 成功 |
| TC-U-036 | tag 带 v 前缀/不带 | 分别发布 `v0.3.0` 与 `0.3.0` 各测一次 | 两次均正确提取版本号 `0.3.0` | 成功 |
| TC-U-037 | 下载地址指向安装包 | Release 附加 `*-setup.exe` asset → 检查更新 → 点下载 | 新窗口打开该 asset 的 `browser_download_url` | 成功 |
| TC-U-038 | 无安装包 asset 回退 | Release 无 exe asset → 检查更新 → 点下载 | 打开 Release 页面链接（回退行为） | 成功 |
| TC-U-039 | 更新日志展示 | Release 正文含多段 Markdown 文本 → 检查更新 | 日志按原文 pre-wrap 展示，超高滚动，不溢出卡片 | 成功 |

## 四、错误处理（TC-U-04x）

| 用例编号 | 场景 | 操作步骤 | 预期结果 | 类型 |
| --- | --- | --- | --- | --- |
| TC-U-041 | 未配置仓库 | 清空配置 → 检查更新 | 提示「尚未配置 GitHub 仓库，请先在下方填写仓库地址」 | 失败 |
| TC-U-042 | 仓库不存在（404） | 填写不存在的仓库 → 检查更新 | 提示 404 对应中文文案；页面其他功能正常 | 失败 |
| TC-U-043 | Token 无效（401） | 私有仓库 + 错误 Token → 检查更新 | 提示「认证凭据无效（401）」 | 失败 |
| TC-U-044 | Token 权限不足（403） | Token 无该仓库 Contents 读权限 → 检查更新 | 提示限流/权限类中文文案 | 失败 |
| TC-U-045 | 断网/超时 | 断开网络 → 检查更新 | 15 秒内返回「连接 GitHub 超时/无法连接」，不悬挂 UI | 失败 |
| TC-U-046 | tag 无版本号 | 发布 tag 为 `release-note` 的 Release → 检查更新 | 提示「未找到版本号（约定 vX.X.X）」 | 失败 |
| TC-U-047 | 失败可立即重试 | 制造一次失败 → 恢复网络 → 再点检查 | 失败结果不缓存，重试立即生效 | 成功 |

## 五、安全与回归（TC-U-05x）

| 用例编号 | 场景 | 操作步骤 | 预期结果 | 类型 |
| --- | --- | --- | --- | --- |
| TC-U-051 | Token 不回显明文 | `GET /api/update/config`（DevTools Network 面板观察） | 响应仅含 `tokenConfigured` 与掩码，无明文 Token | 安全 |
| TC-U-052 | Token 加密落盘 | 打开本地数据库文件查看 `app_settings` 表 | `update.token` 为 AES 密文（三段 base64），非明文 | 安全 |

| TC-U-055 | 关于页其余内容回归 | 打开关于页 | 应用信息卡片、MIT 协议说明等原有内容展示正常 | 回归 |
| TC-U-056 | 设置页其他 Tab 回归 | 遍历通用设置/数据迁移/分类/穿透/帮助 Tab | 全部正常加载，无控制台报错 | 回归 |
| TC-U-057 | 检查中防重复点击 | 检查更新进行中再点「检查更新/保存/测试」 | 按钮禁用（busy 态），不产生并发请求 | 回归 |

---

### 测试数据准备

- 公开仓库 ×1（已发布 ≥1 个符合 `vX.X.X` 的 Release）；
- 私有仓库 ×1（已发布 Release）+ 只读 Fine-grained Token ×1；
- 特殊 tag 仓库（`release-note`、`0.1`、`v0.1.10`）可临时用同一仓库改 tag 覆盖；
- 断网场景可用防火墙拦截 `api.github.com` 模拟。
