# 十期 · 模型路由策略（T06311 / REQ-008 / PRD §B9）

## 结论

T06311 实现已在 `aacb5e7` 落地：按任务特征自动推断类型，在成本、延迟、上下文容量、能力匹配、供应商健康度五个维度筛选候选并打分，结合项目/日/月/单 Run 四档预算输出路由决策；80% 预警、100% 硬停或降级，全部决策写审计。独立验收 **16/16 PASS**；REST 实测 `toolId/model` 手动指定被 400 拒绝。本次为独立复核与回写，无新增代码改动。

## 实现要点

- `server/src/services/ModelRoutingService.ts`：任务类型推断（general/summary/testcase/document/review/code）、候选过滤（健康度 down、上下文不足直接排除）、成本与延迟加权、预算快照、单 Run 上限降级、审计与成本归因。
- `server/src/services/QueueService.ts`：`toolId='auto'` 时先路由再落库，`queue_jobs.tool_id` 写真实工具 ID，不写 `auto` 伪引用；预算硬停发生在插入前。
- `server/src/routes/modelRouting.ts` 挂载 `/api/ai/routing`：`POST /route` 显式拒绝 `toolId`/`model`；`simulate=true` 不写审计不占预算；profiles/budgets/decisions/attribution 接口齐备。
- 增量表：`model_route_profiles`、`model_budgets`、`model_route_decisions`。
