# 十期 · 审批流 UI（T06300 / REQ-007 / PRD §B7）

## 1. 范围

在 Run 详情页为 T06299 风险门禁产生的 `pending` 审批提供人工闭环：查看风险等级、动作、请求者、影响范围、diff、执行预览与超时，填写决策备注后批准或拒绝；不接入第三方 IM，不做审计列表 UI。

## 2. 入口与交互

- `web/src/pages/RunDetailPage.tsx`：当 `trace.approval.status === 'pending'` 时，审批卡片出现「处理审批」按钮。
- 点击后按 `GET /api/run-risk/approvals?runId=<trace.id>&status=pending` 取待审批实体；不使用 `trace.approval.stepId` 当审批 id——那是审批步骤 id，决策需要 `approvals.id`。
- `ApprovalModal` 展示风险徽标（R2 警告色 / R3 危险色）、动作、请求者、Run、创建时间、剩余时间、影响范围、diff 预览、执行预览、决策备注与批准/拒绝按钮。
- diff 按行着色：`+` 绿色、`-` 红色、`@@` 蓝色、`+++`/`---` 次要文字；空 diff 显示明确空态，不伪造内容。
- 批准/拒绝调用 `POST /api/run-risk/approvals/:id/decision`，body `{ decision, actor:'web-ui', reason }`；成功后关闭弹窗、写页脚提示并刷新 Run。
- 弹窗 Esc 使用 capture 阶段阻止冒泡，避免同时触发 Run 详情页「返回」；决策请求期间禁用按钮与关闭，防止重复提交。
- 超时使用未来时点标签「剩余 N 小时/N 天」；不复用只计算过去时间的 `relTime`，避免把 24 小时后误显示为「刚刚」。

## 5. 边界

- 本单只做人工审批弹窗闭环；审计列表查看入口仍禁用，等后续审批审计 UI 单接入。
- 不集成第三方 IM 通知，审批依赖 MTask 内 Run 详情页入口。
- 文件列表展示的是审批实体中的 `diff` 文本，不解析 git diff 结构；超长 diff 在弹窗内滚动。
- 生产库未执行迁移；测试使用隔离数据目录与测试服务。
